## 규칙 쪽에서 본 것

1. 적 상세 머리(`src/app/battle.ts:573`)가 `EnemyDef.art` 를 보지 않는다 — `e.art || 'en_' + e.id` 로 찾으면 위 6종이 배너를 쓴다.
2. 도감 근위기사 줄(`src/ui/codex2.ts:514`)에 `art: 'sm_kalguard'` 가 빠져 있다.
3. `x.art` 로 찾을 때는 별칭(`petrock` · `minos`)을 거치지 않는다. 지금 미노스는 분신을 쓸 수 없어 드러나지 않는다.
4. 자리표시가 궁극기(✦)에만 있다. 무기 · 특성 · 스킬은 아이콘 칸이 사라진다.
5. 편성 화면 포탑 상세가 `heroHead('')` 라 `sm_turret` 배너 대신 머리 아이콘이 나온다.
6. 무기 아이콘은 기물 id 로 고정이라, 능력으로 무기가 바뀌어도 원래 무기 아이콘이 나온다 (라르스 「직접 협상」).
7. 빌드에 있는데 아무도 쓰지 않는 것: 능력 아이콘 `divine.CMD|MARK|SPEC|VAN`, 그림 `sm_slime`.
8. **`art/icons/raw/` 는 깃에 없다** (`.gitignore`). 새 환경에서 `python3 scripts/icons_build.py` 를 돌리면 원본이 없어 `abilicons.gen.ts` 의 249개가 모두 빠진 파일이 만들어진다.
9. 그림 · 아이콘 누락을 잡는 검사가 없다 (`npm run check` 포함).

## 우선순위 제안

1. 궁극기 아이콘 13개 — 프롬프트 작성 → 시안 3개 → 사용자 승인 뒤 유료 생성 (CLAUDE.md 에셋 규칙).
2. 코드 두 줄 — 적 상세 머리 `e.art` (1번), 도감 근위기사 줄 art (2번).
3. 소환물 그림 — 라라 새로 · 녹빛 손은 `sm_slime` 을 쓸지 확인.
4. 적 그림 — 묘석 · 홀로그램.
5. 반려 돌 능력 아이콘을 만들지, 기능 없는 기물은 아이콘 칸을 빼도록 할지.
6. 누락 검사를 `npm run check` 에 추가 (점검에 쓴 스크립트를 옮기면 된다).
