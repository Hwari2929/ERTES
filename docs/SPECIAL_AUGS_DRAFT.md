# 4단계 · 특수군 전용 증강 초안 (기물당 8종)

- 획득: 합류 시 1개 + 7 / 14 / 21등급에 1개씩, 최대 4개. 매번 아직 없는 증강 중 3개를 제시.
- 분류 표기: **강화** = 스킬·특성 수치 상향 / **변형** = 대가가 있는 운용 전환 / **연계** = 아군·시너지 지원.
- 같은 기물 안에서 서로 충돌하는 변형(예: 기본 공격 포기 + 무기 강화)은 함께 제시하지 않음.
- `기존` = 지금 있는 3종 (문구 유지, 수치만 6단계에서 조정).
