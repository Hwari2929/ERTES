### 2.7 상점에서 산 아이템별 성과 (영희, 산 런 20개 이상)

## 3. 해석

| 관찰 | 해석 |
|---|---|
| 클리어 철수와 오차 안 (−3.0 ± 4.3%p) | 공명도 80% 경제와 함대 · 시너지 경제가 고난에서 비슷한 결과. 사용자 방식이 봇 기준으로 손해는 아니다 |
| 등급 14.2 → 9.6, 출전 7.5 → 9.4, 2단계 시너지 71 → 97% | 공명도 대신 폭(인원 · 시너지)을 샀다. 철수 평가는 공명도를 장비보다 크레딧당 3~25배 높게 보지만, 실제 결과는 비슷하다 → 철수 평가(V)가 넓은 편성 · 시너지 가치를 덜 쳐 줄 가능성 |
| P1 보스 91 → 78% | 바닥 40 은 P1 에서 가장 비싸다 (시작 0 크레딧, 공명도 거의 못 삼). 진짜 플레이어도 P1 보스에서 이 손해를 볼 수 있다 |
| P6 영희 끝 크레딧 88 → 영희_last 25, 짝 +2.4 ± 2.3%p | 마지막 페이즈의 이자는 쓸 곳이 없다. 사용자에게 '마지막 페이즈는 다 쓰기'가 권할 만한 수정 |
| 보급 72.8 → 0.4% | 영희 점수식은 시너지 목표가 거의 늘 있어 영입이 보급(1.3 sup)을 이긴다. 보급의 무료 가치가 빠져도 결과가 비슷 → 보급 노드의 상대 가치가 낮을 수 있다 (밸런스 관찰 후보) |
| 이자 69 → 138 | 바닥 40 의 직접 효과. 이자 상한 도달 52% (상한 4 = 40 크레딧, 그 위는 이자 없음) |
