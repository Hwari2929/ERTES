# 상호작용 대사 (BANTER)

기물끼리 주고받는 짧은 만담 모음 (664편, 57기 전원 13회 이상 등장). 에란테스 바 허브(src/ui/bar.ts)에서 쓴다 (`npm run banter` 로 src/data/bar/banter.gen.ts 생성). 같은 개그가 여러 편에 반복되면 하나만 남긴다 (2차 정리: 스콜치 / 지르곤 / 땅콩버터 범인 / 부계정 / 점검구 미사일 중복 6편 삭제).

- 말투는 `docs/VOICES.md` (인물별 4칸 · 대상별 어체), 문장은 `docs/SCENES.md` '대사 지침 6차', 연출은 3차 지침을 따른다. 코미디 우선, **2~7줄 · 아래 '장면 모양' 쿼터**, 경구 · 로어 낭독 금지.
- 바 무대는 4명이다 (레이첼은 카운터 안 = 무대 밖). 바에서 재생되는 만담은 레이첼을 빼고 출연 4명까지 — 넘으면 영영 재생되지 않아 `npm run check` (`tests/bar_check.ts`) 가 실패한다.
- **바 무대에는 상황 줄이 없다** (2026-11-01). 머리줄의 '상황 한 줄'은 도감 · 통신 기록에만 나온다. 바에서 재생되는 만담(바 · 어디서나)은 보이는 것 — 무대의 인물(낮이면 에이든), 동물(리키 · 맥스 · 밍키), 카운터 위 잔 · 소품, 조명(낮 · 밤) — 과 대사만으로 읽혀야 한다. 정황이 상황 줄에만 있으면 대사로 드러내거나, 바 밖 일이면 통신 기록(바 밖) 만담으로 옮긴다.
- **당직은 언제나 레이첼**이고 에이든은 **낮에만** 출근한다. 단원이 바 당직을 서는 장면 · 밤의 에이든은 바 무대에서 성립하지 않는다.
- 지휘관 = 레이첼. 에란테스 바는 **지상의 진짜 바**이고, 함대 · 함선은 따로다 (함선 안 술자리는 식당 · 휴게실).
- 아문센은 지휘하지 않는다 (참견 · 옛날 얘기만). 은퇴 여부도 확정하지 않는다.
- 엘베스타드 본가 식구(시그문드 · 구닐라 · 라스무스 · 밍키)가 함선 · 바에 있으면 상황 줄에 따라온 이유를 깐다.
- 카일 = 로마니가 찾는 가주인지, 카부라야 = 레이카 0호인지, 마오의 실물은 확정하지 않는다.

형식: `**A × B** — 상황 한 줄` 다음 줄부터 `A: …`. 화자 이름은 기물 이름 (망명 혈족 귀공자 = 귀공자, 오닉스 감응자 = 오닉스, 테르모필레 = 테르모필레).

머리줄 끝 표시 (`scripts/banter_build.mjs` 가 읽는다, 여러 개를 이어 붙인다):

| 표시 | 뜻 |
|---|---|
| 〔낮〕 · 〔밤〕 | 그 조명일 때만 바에서 재생한다 (에이든이 나오면 낮, 새벽 · 심야 · 취기면 밤) |
| 〔소품: 이름, 이름〕 | 그 장면 동안 말하는 사람 앞 카운터에 놓는다 (`src/ui/barprops.ts` 이름 → 아이콘, 잔 종류는 음료 그림) |
| 〔동물: 리키〕 | 카운터에 동물을 올려 앉힌다 (주인 앞, 그 동물이 화자로 무대에 서 있으면 그리지 않는다) |
| 〔바 밖〕 | 바 밖 일 → 통신 기록에만 나온다 |
| 〔보류〕 | 내보내되 재생하지 않는다 (설정 확정 전: 카일 · 데미우르고스) |
| 〔삭제〕 | 내보내지 않는다. 번호는 그대로 세서 뒤 편의 id 가 밀리지 않는다 |

같은 표시를 틀(`frames_*.ts`)은 `time` · `props` · `pets`(인물 → 동물) 칸으로, 작별 · 혼잣말은 줄 앞 `〔낮〕 ` · `〔밤〕 ` 접두로 단다.

## 장면 모양 (6차 · 2026-11-01)

모든 만담을 4줄 셋업-펀치(A-B-A-B)로 쓰지 않는다. 새로 쓰거나 고쳐 쓰는 만담은 아래 모양 중 하나로 쓰고, 머리줄 끝에 모양 태그를 단다 (예: `**A × B** — 상황 〔받아치기〕`, 빌드 · 검사가 읽는다). 바 무대에서 만담은 시간의 약 15%뿐이고 나머지는 이모티콘 · 혼잣말 · 정적이라, 짧은 모양의 몫을 크게 둔다. 쿼터는 제안값이다.

| 모양 (태그) | 줄 | 어떻게 쓰나 | 쿼터 |
|---|---|---|---|
| 2줄 받아치기 〔받아치기〕 | 2 | 툭 던지고 같은 틀로 받아친다. 상대의 단어나 어미를 되받아 비튼다 | 15% |
| 혼자 투덜 + 한마디 〔투덜〕 | 2~3 | 한 사람이 길게 투덜대고, 상대는 한마디 · 이모티콘 · 몸짓으로 끝낸다 | 15% |
| 셋업-펀치 〔펀치〕 | 3~4 | 지금의 기본형. 쓰더라도 화자 순서를 A-B-B-A · A-A-B 처럼 흔든다 | 20% (상한 25%) |
| 확전 〔확전〕 | 5~7 | 한쪽의 허세 · 거짓말에 상대가 장단을 맞춰 키우다 무너진다 | 10% |
| 3인 역할 충돌 〔3인〕 | 4~6 | 벌이는 쪽 · 지적하는 쪽 · 뒤집는 쪽. 각자 자기 버릇 한 줄만 던지고 빠진다. 끼어들기 틀의 @0 자리와 맞춘다 | 10% |
| 끊긴 대화 〔끊김〕 | 2~4 | 호출 · 바 사건(에이든이 잔을 내옴 · 누가 들어옴) · 다른 인물로 중간에 끊긴다. 마무리 줄이 없다 | 10% |
| 한 방 없이 끝나는 편 〔여운〕 | 3~4 | 서운함 · 의외의 다정함 · 허세가 들통남 같은 관계 비트로 끝난다 | 10% |
| 반복 개그 회수 〔회수:id,id〕 | 2~5 | 앞선 만담(태그에 id)을 전제로 꺼내 뒤집거나 세어서 터뜨린다. 깔린 편을 본 뒤에만 재생된다 | 10% |

- 줄 수 목표: 2~3줄 40% 안팎 · 4줄 30% 이하 · 5줄 이상 15% 이상. 같은 배치(한 번에 쓰는 묶음) 안에서 같은 모양을 2편 연달아 쓰지 않는다.
- 모든 줄이 농담일 필요는 없다. 줄마다 농담 · 캐릭터 · 상황 가운데 하나만 하면 된다. 질문에 바로 답하지 않는 줄(비약 · 반대로 말하기 · 숨기기)을 섞는다.
- **딴죽은 말이 아니어도 된다.** 침묵 · 무반응 · 지문 · 바 무대의 이모티콘(💢 · 💦 · … 등, `src/ui/baremote.ts`)도 딴죽이다.
- **진지함 뒤에는 펀치를 붙이지 않는다.** 순서는 개그 → 계기(사건 · 침묵 · 위협) → 한 사람의 짧은 진지한 반응 → 지문 · 이동으로 닫기. 예외는 농담으로 덮는 것이 그 인물의 '새어 나오는 방식'일 때(필리스).
- **반복 개그는 세어서 회수한다.** 2~3편에 깔고 다음 편에서 누군가 세거나 뒤집는다. 소재 한도는 `docs/MOTIFS.md`.

## 작성 공정 (6차)

1. **작게 쓴다.** 한 번에 1~2명 × 3~5편. 수십 편을 한꺼번에 뽑지 않는다.
2. **모양 카드를 먼저 정한다.** 편마다 모양 · 줄 수 · 층 · 트리거(무엇이 이 대화를 시작시키나)를 쿼터에 맞춰 정해 놓고 쓴다.
3. **예시는 바꿔 가며 넣는다.** 모양이 서로 다른 좋은 예시 2~3편을 넣고 묶음마다 교체한다. 이전 만담을 통째로 맥락에 넣지 않는다 (같은 꼴로 수렴한다). 중복은 소재 검사 · 린트로 잡는다.
4. **후보 여럿에서 고른다.** 구조가 다른 후보를 3~5개 쓰고, 가장 뻔하지 않은 것을 고른다.
5. **쓰기와 고치기를 나눈다.** 쓸 때는 해야 할 것(어미 · 담화표지 · 호칭 · 모양)만 지시하고, 금지 목록은 고치기 단계와 `tests/banter_lint.ts` 로 거른다. 고칠 때는 걸린 줄만 고친다 (한 편의 30% 넘게 바뀌면 다시 본다).
6. **마지막은 소리 내어 읽기.** 사람이 고친 전후를 모아 반복되는 수정을 규칙 · 린트에 올린다.

## 층 · 끼어들기 만담 (바 허브 2차)

- 만담마다 층 태그가 붙는다 (`scripts/banter_build.mjs` 의 `LAYER_FIX`): 표면(말버릇 · 소재) · 이상(가치 · 입장) · 실재(상처 · 기제). 기존 만담은 거의 다 표면이다. 이상 · 실재는 키워드가 잘못 걸리기 쉬워 수동으로만 올린다.
- 새 만담은 `src/data/bar/frames*.ts` 의 '핵심 틀 + 끼어들기 슬롯' 구조로 쓴다: 핵심 두 인물의 대화 사이 `@0` 자리에, 그때 바에 있는 세 번째 단원의 대사가 들어간다 (후보 5~7명, 없으면 건너뜀). 주제는 뜬금없는 소리 · 요즘 유행 · 시사 · 진지한 토론.
- 실재 층은 노출의 약 10%, 심야 장면이며, 그 인물과 가까워진 뒤에 열린다 (바에서 말 건 횟수 + 함께 출전한 런 수 ≥ 6). 고백하지 말고 docs/VOICES.md '새어 나오는 방식'으로 쓴다.
- 소재 반복은 `npm run check` 의 소재 검사가 경고한다 (docs/MOTIFS.md).
