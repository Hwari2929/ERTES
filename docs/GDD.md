# ERRANTEs 기획 정리 (프로토타입 v0.1)

> 표기: **[확정]** 기획자가 정한 내용 · **[임시]** 아직 안 정해서 프로토타입용으로 넣은 값.
> 수치는 거의 모두 `src/config.ts` 한 곳에 모여 있습니다.

## 1. 방향성
- [확정] 싱글 PvE 오토배틀러. 오프라인 플레이, 저장·불러오기 자유. PvP·상점 리롤·3합성 없음.
- [확정] 무한 모드. 페이즈마다 적 방어도 ×1.25, 피해 증폭 ×1.4 (복리, 구 ×1.35).
- [확정] 적 체력 배율: 5페이즈까지 페이즈당 ×2.05 (구 ×2), 6페이즈부터 ×1.9, ×1.8, ×1.7 … 으로 감소. [임시] 하한 ×1.1 (14페이즈 이후).
  누적 배율 (고페이즈 보정 포함): 체력 P5 ×16.8, P6 ×30, P7 ×52, P8 ×84, P10 ×181 / 피해 P5 ×4.2, P6 ×6.4, P7 ×9.8, P8 ×14.9, P10 ×34.7.
- [확정] 고페이즈 보정: 5페이즈부터 매 페이즈 체력 ×0.95, 피해 ×1.09를 추가로 곱함 ([임시] 계수). 8페이즈 기준 체력 −19%, 피해 +41% (P10 −26% / +68%).
- [확정] 이름 ERRANTEs = 세계관 속 용병 집단의 이름.

## 2. 런 흐름
- [확정] 시작 기물 4명 선택 → 2페이즈부터 매 페이즈 첫 노드(영입)에서 3명 중 1명 영입. 1페이즈에는 영입 노드 없음. 출전 최대 10명, 보유 최대 16명 (대기 6명). 16명이 차면 영입 노드는 크레딧 +10으로 대체.
- [확정] 노드 종류: 일반 전투 / 역경 / 상점 / 보급 / 기물 영입 / 사건 / 보스.
- [확정] 페이즈 구성 (11칸): `영입 → 전투 → 사건 → 전투 → 보급 → 전투 → 사건 → 역경 → 보급 → 역경 → 보스`. 보급 = 상점 / 보급 중 선택. 1페이즈는 시작 기물이 4명이라 영입 없이 10칸.
- [확정] **6페이즈 보스를 이기면 의뢰 성공.** 귀환(런 종료)하거나 무한 모드로 계속할 수 있음. 성공하면 다음 위험 등급 해금.
- [확정] 위험 등급 (난이도) 0~8. 단계 n은 1~n 조건을 모두 포함: ① 적 체력 +15% ② 적 피해 +15% ③ 시작 크레딧 0, 이자 상한 −1 ④ 보스 체력 +25%, 보스 호위 +1 ⑤ 역경 적 +1, 정예 출현 2배 ⑥ 최대 플레이어 체력 −25 ⑦ 적 방어도 +25%, 효과 저항 +15%p ⑧ 페이즈마다 적 체력 +5% 누적.
- [확정] 사건 노드: 전장별 사건 + 공용 사건. 선택지마다 판을 바꾸는 효과 (기물 추가 영입, 장비 1개 → 무작위 2개, 이자 상한 −3 대신 노드마다 크레딧 +2, 사건 전용 기물, 페이즈 · 영구 팀 효과 등). 일반 사건은 같은 런에서 반복될수록 덜 나오고, 희귀 사건은 런당 1회.
  - 희귀: **아문센의 보물 창고** (가중치 0.04, 무작위 세력 문장 7개) · **얼굴 없는 중개인** (0.06, 크레딧 전부 + 최고 등급 기물 이번 페이즈 출전 불가 ↔ 보유·장착 장비 전부 전설).
  - 사건 전용 기물 6명: 밍키 (공용), 오닉스 감응자 (물류망), 망명 혈족 귀공자 (크림슨), 테르모필레 (스파르타), U-404 (페트라), 루스 (황무지). 시작 기물 · 영입 노드에는 나오지 않음.
- [확정] 기물 방출: 크레딧 3 + 공명 등급×2, 이 기물에 쌓인 공명도의 60%를 남은 파티에 분배, 장비 · 개조부품은 보관함으로 (고유 장비는 소멸). 확인 단계를 거침.
- [확정] 도감 · 기록 (런 사이 유지): 기물별 짧은 이야기, 의뢰(기용한 런) 수, 누적 공명 등급, 최고 등급, 성공 수 / 적별 조우 · 처치 수 / 겪은 사건 / 전장별 의뢰 · 성공 · 최고 위험 등급.
- [확정] 플레이어 체력(목숨) 시스템. [임시] 체력 100, 패배 피해 `3 + 2×페이즈 + 생존 적 수`, 보스 패배 `10 + 3×페이즈`. 보스는 이길 때까지 재도전.
- [임시] 출전 인원 상한 `3 + 페이즈` (최대 10).
- [확정] 특권 증강: 런 시작 시 1개 선택, 새로고침 3회 (선택지 3개 전체 교체). [임시] 종류:
  - **문장** (가중치 4): 해당 시너지 문장 개조부품 1개. 70% 확률로 시작 기물의 시너지 중에서 나옴.
  - **추가 계약**: 기물 3명 중 1명 즉시 영입 · **가보**: 전설 장비 3개 중 1개 · **베테랑 편성**: 시작 기물 전원 공명 등급 +2
  - **작전 재량**: 전역 증강 1개 추가 · **후원금**: 크레딧 +40 · **보험 가입**: 최대 플레이어 체력 +40
- [확정] 전역 증강: 런 시작 시 + [임시] 3페이즈마다 1개 선택. 시너지 관련 전역 증강:
  - 문장 수여 (중첩 가능): 출전 중인 시너지 중 무작위 1개의 문장 개조부품
  - 연합 협정 / 전술 교범: 출전 인원이 가장 많은 세력 / 특성 +1pt
  - 결속: 활성 시너지 1개당 모든 아군 피해 +3% · 정점: 최고 단계 시너지 1개당 피해 +10%, 받는 피해 −5%
  - 다국적 편성: 활성 세력 시너지 3개 이상이면 받는 피해 −12%, 공격 속도 +10%
  - 인맥: 영입 선택지 +1, 파티와 시너지가 겹치는 기물이 더 자주 나옴
- [확정] 전장: 런마다 1곳 (무작위). 런 시작 시 브리핑으로 보여주고, 상단 바와 지도 화면에 계속 표시. 전장마다 일반 적 4~8종, 정예 1종, 보스 2~3종(페이즈마다 순환)과 전장 조건, 해당 세력 기물 보너스가 있음. 적 스프라이트는 [임시] 플레이스홀더.

  | 전장 | 세력 · 지역 | 적 | 조건 | 세력 보너스 |
  |---|---|---|---|---|
  | 베르타–산노디스 물류망 | 연합 · 군체 침식 전선 | 군체 (포자 살점, 사냥개체, 산성 분사체, 마부 개체 / 산란체 / 군체 여왕, 거대 마부 개체) | 엘리트·보스 생존 시 적 피해 +20% | 연합 피해 +20%, 메이저 +3 |
  | 크림슨 대공령 | 제국 · 북부 변방 | 혈족 (종자, 배양 사냥개, 정맥관 총사, 배양조 사제 / 혈기사 / 혈족 백작, 그라나툼 심핵 수호체) | 적 흡혈 15% | 제국 피해 +20%, 방어도 +150 |
  | 스파르타 전쟁 궤도 | 동맹 · 최전선 | 메카 (호플리테, 창병, 궤도 사수, 예인 드론 / 팔랑크스 지휘기 / 콜로서스, 창구 절멸 포대) | 적 방어도 +20% | 동맹 피해 +20%, 효과 명중 +20%p |
  | 페트라 본사 성역 | 페트라 · 격리 구역 | 보안 로봇, 감시 드론, 유닉스 생산 로봇, 격리 이탈 개체 / 정보감사관 / 계약서에 없던 것, 유닉스 생산 라인 | 승리 크레딧 +2, 적 효과 저항 +25%p | 페트라 피해 +20%, 받는 피해 −10% |
  | 황무지 성계 | 무법 변경 | 기존 약탈자 · 공허 · 기계 / 약탈자 두목 / 바르가, 골리앗, 닉스 | 적 +1, 재료 드랍 ×2, 상점 +25% | 범은하 공동체 피해 +20% |
- [임시] 영입 기물은 `공명 등급 = 페이즈 − 1`로 합류하고, 올라간 등급만큼 스탯 배분·증강 선택을 바로 진행.

## 3. 전투
- [확정] 배치 후 완전 자동. 6×6 기본, 전장에 따라 5×5 / 7×7. 적과 같은 보드를 반씩 사용.
- [확정] 기본 공격은 기물마다 사격 또는 타격 고정. 기술은 쿨다운만 사용 (마나 없음).
- [확정] 명중: `80% + 추가 명중 − 추가 회피`. 빗나가면 `min(80%, 30% + 명중×0.5)` 확률로 찰과상 → 원래 피해의 `min(50%, 20% + 명중×0.25)`.
- [확정] 방어도: `경감 = A(1−관통) / (A(1−관통) + 2000)`.
- [확정] 속성:

| 속성 | 방어도 적용 | 치명타 | 특수 |
|---|---|---|---|
| 물리 | 100% | O | — |
| 화학 | 50% | X | 생체 ×1.5 |
| 전기 | 50% | X | 기계 ×1.5 |
| 정신 | 0% | X | 기계 ×0.25 |
| 신성 | 50% | X | 버프 계수가 높음 (성직자 시너지와 함께 구현 예정) |
| 고정 | 0% | X | 경감 무시 |

- [확정] 증가(%p)끼리는 합연산, 같은 종류 증폭(%)은 최대값만 적용, 증가와 증폭은 곱연산, 다른 종류끼리도 곱연산.
  - 구현: 종류 = `전체 / 속성 / 기본공격 / 기술 / 지속피해 / 추가타`. 조건부 보너스(“체력 50% 이하일 때” 등)는 각각 별도 종류로 곱연산.
- [확정] 적 키워드는 생체 / 기계 / 건물 / 환상 중 1개 이상.
- [임시] 상태이상 확률 = `기본 확률 × (1 + 효과 명중 − 효과 저항)`. 보스는 기절·공포 지속시간 절반.
- [임시] 상태이상: 기절, 공포(공격·기술 불가), 감전(쿨다운 정지, 전기), 중독(화학 지속 피해), 출혈(물리 지속 피해), 부식(방어도 감소), 둔화.
- [임시] 45초부터 연장전(초당 피해 +10%), 75초가 지나면 패배.

## 4. 스탯 · 성장
- [확정] 메이저 5종 → 마이너 고정값. 실제 전투에는 마이너 스탯만 쓰임.
- [임시] 환산표 (메이저 1pt당):

| 메이저 | 마이너 |
|---|---|
| 생명력 | 최대 체력 +60, 회복 효율 +2% |
| 전투력 | 사격·타격 위력 각 +5, 치명타 확률 +2%p |
| 정신력 | 기술 위력 +5, 명중 +2%p, 효과 명중 +3%p |
| 방어력 | 방어도 +60, 효과 저항 +3%p |
| 기동력 | 이동 속도 +4%, 회피 +2%p |

  기초값: 체력 300, 위력 20, 방어도 100, 치명타 5% / 150%.
- [확정] 공명 등급은 99까지. **5의 배수 등급마다 기물 전용 증강 1개** (공용 · 시너지 증강 풀은 제거).
- [확정] 등급업마다 모든 메이저 +1 자동. **3의 배수 등급**에는 서로 다른 메이저 2개를 골라 각각 +3.
- 칼리토 작위: 4 남작 / 7 백작 / 10 공작 / 15 대공 / 20 황족.
- [확정] 전투가 끝나면 파티 전원이 공명도 풀을 무작위로 나눠 가짐. 출전 기물은 최소 1pt, 대기 기물은 가중치 0.5 ([임시]).
- [임시] 공명도 풀 `6 + 3×페이즈`, 다음 등급까지 `2 + 2×현재 등급` (1→2: 4pt … 9→10: 20pt).
- [임시] 공명도 구매: 크레딧 4 → 4pt.

## 5. 증강
- [확정] 공명 등급 5 · 10 · 15 · 20 · 25에 기물 전용 증강 3개 중 1개 선택, 새로고침 1회. 공용 · 시너지 증강 풀은 제거됨. 기물마다 전용 증강 5개 (25등급이면 전부 획득).
- 사건 [의뢰하지 않은 꿈]으로 전용 증강을 추가로 얻을 수 있음.

## 7. 장비 · 경제
- [확정] 개조부품 슬롯 1 (장비 3칸과 별도). 지금은 문장만 있음: 장착한 기물이 해당 시너지에 추가 소속 (이미 소속된 시너지의 문장은 장착 불가). 획득처: 특권 [문장], 전역 [문장 수여].
- [확정] 슬롯 3, 부위 없음, 자유 교체. 재료(일반) 2개 → 고급, 전설은 효과 3배.
- [임시] 재료 5종 = 메이저 +3. 고급 15종 = 재료 두 개 스탯 + 고유 효과. **같은 고급 2개 → 전설**.
- [확정] 수입 = 노드 보상 + 이자 + 연승 보너스. [임시] 승리 `5 + ⌊페이즈/2⌋`, 패배 2, 이자 10당 1 (최대 5), 연승 2/4/6 → +1/+2/+3.
- [임시] 상점 가격 재료 7 / 고급 22 / 전설 60, 판매 3 / 8 / 20.
- [확정] 장비는 적게, 전설은 매우 희귀하게. [임시] 획득 경로:
  - 일반 전투 승리 10%, 역경 50% 확률로 재료 1개.
  - 보스: 3페이즈마다 고급 장비 3개 중 1개, 그 외 페이즈는 50% 확률로 재료 3개 중 1개.
  - 상점: 재료 1개, 고급 25%, 전설은 6페이즈부터 5%.
  - 보급 [고급 장비] 12%, 속보 [스폰서 계약] 12명성, [명예의 전당] 45명성. 전역 [무기고 개방] 재료 2개.
  - 봇 기준 사망 시 보유 장비(재료 환산)가 23.6 → 12.3개, 전설 0.15 → 0.03개.
