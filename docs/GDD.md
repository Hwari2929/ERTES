# ERRANTEs 기획 정리 (프로토타입 v0.1)

> 표기: **[확정]** 기획자가 정한 내용 · **[임시]** 아직 안 정해서 프로토타입용으로 넣은 값.
> 수치는 거의 모두 `src/config.ts` 한 곳에 모여 있습니다.

## 1. 방향성
- [확정] 싱글 PvE 오토배틀러. 오프라인 플레이, 저장·불러오기 자유. PvP·상점 리롤·3합성 없음.
- [확정] 무한 모드. 페이즈마다 적 방어도 ×1.25, 피해 증폭 ×1.4 (복리, 구 ×1.35).
- [확정] 적 체력 배율: 5페이즈까지 페이즈당 ×2.05 (구 ×2), 6페이즈부터 ×1.9, ×1.8, ×1.7 … 으로 감소. [임시] 하한 ×1.1 (14페이즈 이후).
  누적 배율 (고페이즈 보정 포함): 체력 P5 ×16.8, P6 ×30, P7 ×52, P8 ×84, P10 ×181 / 피해 P5 ×4.2, P6 ×6.4, P7 ×9.8, P8 ×14.9, P10 ×34.7.
- [확정] 고페이즈 보정: 5페이즈부터 매 페이즈 체력 ×0.95, 피해 ×1.09를 추가로 곱함 ([임시] 계수). 8페이즈 기준 체력 −19%, 피해 +41% (P10 −26% / +68%).
- [확정] 이름 ERRANTEs = 세계관 속 용병 집단의 이름.

## 2. 런 흐름
- [확정] 시작 기물 3명 선택 → 페이즈 중간 영입 노드에서 3명 중 1명 영입. 출전 최대 10명, 보유 최대 16명 (대기 6명). 16명이 차면 영입 노드는 크레딧 +10으로 대체.
- [확정] 노드 종류: 일반 전투 / 역경 / 상점 / 보급 / 기물 영입 / 보스.
- [임시] 페이즈 구성 (8칸, 전투 노드 5개):
  `전투 → 전투|역경 → 영입 → 상점|보급 → 전투|역경 → 전투 → 상점|보급 → 보스`
- [확정] 플레이어 체력(목숨) 시스템. [임시] 체력 100, 패배 피해 `3 + 2×페이즈 + 생존 적 수`, 보스 패배 `10 + 3×페이즈`. 보스는 이길 때까지 재도전.
- [임시] 출전 인원 상한 `3 + 페이즈` (최대 10).
- [확정] 전역 증강: 런 시작 시 + [임시] 3페이즈마다 1개 선택.
- [임시] 영입 기물은 `공명 등급 = 페이즈 − 1`로 합류하고, 올라간 등급만큼 스탯 배분·증강 선택을 바로 진행.

## 3. 전투
- [확정] 배치 후 완전 자동. 6×6 기본, 전장에 따라 5×5 / 7×7. 적과 같은 보드를 반씩 사용.
- [확정] 기본 공격은 기물마다 사격 또는 타격 고정. 기술은 쿨다운만 사용 (마나 없음).
- [확정] 명중: `80% + 추가 명중 − 추가 회피`. 빗나가면 `min(80%, 30% + 명중×0.5)` 확률로 찰과상 → 원래 피해의 `min(50%, 20% + 명중×0.25)`.
- [확정] 방어도: `경감 = A(1−관통) / (A(1−관통) + 2000)`.
- [확정] 속성:

| 속성 | 방어도 적용 | 치명타 | 특수 |
|---|---|---|---|
| 물리 | 100% | O | — |
| 화학 | 50% | X | 생체 ×1.5 |
| 전기 | 50% | X | 기계 ×1.5 |
| 정신 | 0% | X | 기계 ×0.25 |
| 신성 | 50% | X | 버프 계수가 높음 (성직자 시너지와 함께 구현 예정) |
| 고정 | 0% | X | 경감 무시 |

- [확정] 증가(%p)끼리는 합연산, 같은 종류 증폭(%)은 최대값만 적용, 증가와 증폭은 곱연산, 다른 종류끼리도 곱연산.
  - 구현: 종류 = `전체 / 속성 / 기본공격 / 기술 / 지속피해 / 추가타`. 조건부 보너스(“체력 50% 이하일 때” 등)는 각각 별도 종류로 곱연산.
- [확정] 적 키워드는 생체 / 기계 / 건물 / 환상 중 1개 이상.
- [임시] 상태이상 확률 = `기본 확률 × (1 + 효과 명중 − 효과 저항)`. 보스는 기절·공포 지속시간 절반.
- [임시] 상태이상: 기절, 공포(공격·기술 불가), 감전(쿨다운 정지, 전기), 중독(화학 지속 피해), 출혈(물리 지속 피해), 부식(방어도 감소), 둔화.
- [임시] 45초부터 연장전(초당 피해 +10%), 75초가 지나면 패배.

## 4. 스탯 · 성장
- [확정] 메이저 5종 → 마이너 고정값. 실제 전투에는 마이너 스탯만 쓰임.
- [임시] 환산표 (메이저 1pt당):

| 메이저 | 마이너 |
|---|---|
| 생명력 | 최대 체력 +60, 회복 효율 +2% |
| 전투력 | 사격·타격 위력 각 +5, 치명타 확률 +2%p |
| 정신력 | 기술 위력 +5, 명중 +2%p, 효과 명중 +3%p |
| 방어력 | 방어도 +60, 효과 저항 +3%p |
| 기동력 | 이동 속도 +4%, 회피 +2%p |

  기초값: 체력 300, 위력 20, 방어도 100, 치명타 5% / 150%.
- [확정] 공명 등급은 10을 넘어서도 계속 오름. 10등급까지는 등급업마다 증강 선택, 11등급부터는 스탯만 오르되 5등급마다(15, 20, 25 …) 시너지 · 공용 증강 풀에서 1개 추가 선택 (전용 증강 제외).
- [확정] 등급업마다 모든 메이저 +1 자동, 그리고 서로 다른 메이저 2개를 골라 각각 +1 (5의 배수 등급은 +5). 등급당 7pt, 5의 배수 등급 15pt. 상한 99등급.
- 칼리토 작위: 4 남작 / 7 백작 / 10 공작 / 15 대공 / 20 황족.
- [확정] 전투가 끝나면 파티 전원이 공명도 풀을 무작위로 나눠 가짐. 출전 기물은 최소 1pt, 대기 기물은 가중치 0.5 ([임시]).
- [임시] 공명도 풀 `6 + 3×페이즈`, 다음 등급까지 `2 + 2×현재 등급` (1→2: 4pt … 9→10: 20pt).
- [임시] 공명도 구매: 크레딧 4 → 4pt.

## 5. 증강
- [확정] 등급업마다 3개 중 1개 선택, 새로고침 1회. 3·6·9단계는 기물 전용 증강만.
- [확정 구조 / 임시 수량] 기물 전용 11개, 시너지 공용 10개, 전체 공용 10개 → 프로토타입은 **전용 5 · 시너지 4 · 공용 12**.
- [임시] 일반 등급업 시 출처 가중치: 전용 30% / 시너지 40% / 공용 30%.

## 7. 장비 · 경제
- [확정] 슬롯 3, 부위 없음, 자유 교체. 재료(일반) 2개 → 고급, 전설은 효과 3배.
- [임시] 재료 5종 = 메이저 +3. 고급 15종 = 재료 두 개 스탯 + 고유 효과. **같은 고급 2개 → 전설**.
- [확정] 수입 = 노드 보상 + 이자 + 연승 보너스. [임시] 승리 `5 + ⌊페이즈/2⌋`, 패배 2, 이자 10당 1 (최대 5), 연승 2/4/6 → +1/+2/+3.
- [임시] 상점 가격 재료 7 / 고급 22 / 전설 60, 판매 3 / 8 / 20.
- [확정] 장비는 적게, 전설은 매우 희귀하게. [임시] 획득 경로:
  - 일반 전투 승리 10%, 역경 50% 확률로 재료 1개.
  - 보스: 3페이즈마다 고급 장비 3개 중 1개, 그 외 페이즈는 50% 확률로 재료 3개 중 1개.
  - 상점: 재료 1개, 고급 25%, 전설은 6페이즈부터 5%.
  - 보급 [고급 장비] 12%, 속보 [스폰서 계약] 12명성, [명예의 전당] 45명성. 전역 [무기고 개방] 재료 2개.
  - 봇 기준 사망 시 보유 장비(재료 환산)가 23.6 → 12.3개, 전설 0.15 → 0.03개.

- 5~6페이즈 보스 승률이 22~27% → 30~32%로 소폭 상승 (보스 체력 감소 효과). 7페이즈부터는 피해 상승분이 더 크게 작용.
- 봇은 상점·조합을 거의 쓰지 않으므로, 실제 플레이는 장비가 이보다 조금 더 많음.

### v0.1
`npm run sim -- 30` (아무 증강이나 고르는 단순 봇 30판):

| 페이즈 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 전투 승률 | 85% | 95% | 95% | 88% | 85% | 83% | 68% | 32% |

- 봇은 대부분 **7~8페이즈**에서 끝남. 이때 평균 공명 등급이 9.6이라 성장이 거의 다 끝난 상태.
- 원인: 적 체력은 `2^(페이즈−1)`로 지수 성장(8페이즈 = 128배)하는데, 플레이어 성장(스탯 +2pt/등급, 장비, 인원 +1/페이즈)은 대략 선형. 그래서 벽이 갑자기 옴.
- 사람이 증강을 맞춰 고르면 1~3페이즈 더 버틸 것으로 예상. "무한 모드는 결국 끝나고, 기록 경쟁"이 목표라면 지금 구조로 충분. 더 길게 가려면 체력 배율을 낮추거나(예: ×1.6), 후반 성장 축(증강 중첩, 전설 장비, 시너지 6단계)을 늘려야 함.

## 9. 다음에 정해야 할 것
1. 메이저→마이너 환산표 (지금은 [임시] 값)
2. 공명도 풀 크기 / 등급별 필요량 / 무작위 분배 방식 (지금은 가중치 무작위)
3. 등급업 포인트를 자유 배분할지, "서로 다른 스탯 N개 선택"으로 할지
4. 출전 인원 상한 규칙
5. 패배 시 체력 피해 공식, 시작 체력
6. 전설 장비 획득 경로 (지금은 같은 고급 2개 조합 + 6페이즈 이후 상점 5% + 속보 노드 45명성)
9. 체력 배율 감쇠의 하한 (지금 ×1.1), 피해 증폭 ×1.35도 감쇠시킬지
7. 런 사이 메타 진행 (영구 해금 등)
8. 미구현 시너지 5 + 세력 2 상세 설계 (특히 은하 대스타의 순례/속보 노드, 명성 스택)
