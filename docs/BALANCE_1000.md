# 밸런스 분석: 시뮬레이션 1000판 (리워크 1차 + 이야기 사건 64종)

> 재현: `npx esbuild tests/analyze.ts --bundle --platform=node --outfile=dist/analyze.cjs` → `node dist/analyze.cjs <시작> <판 수> [noTurret|noBlink] > runs.jsonl`,
> 메타 `tests/analyze_meta.ts` → `meta.json`, 집계 `python3 tests/analyze_report.py`, `python3 tests/analyze_events.py` (같은 폴더에 runs.jsonl · meta.json).

- 페이즈별 승률 (일반 / 역경 / 보스): P1 99.7 / 83.5 / 82.8 · P4 97.2 / 80.8 / 76.3 · P5 94.7 / 72.6 / 70.9 · P6 91.8 / 65.9 / **44.1**.

## 3. 기물
시작 기물 성공률 (무작위 4명이라 인과에 가까움, 기준 34.4%, 표본 약 100 → ±9%p).

## 4. 시너지 완성률이 매우 낮다
| 시너지 | 1단계 / 2단계 / 3단계 도달 | 구조 |
|---|---|---|
| 세력 7종 | 17~28% / 1~7% / ~0% | 일반 기물이 세력당 6명뿐이라 **7명(3단계)은 문장 없이 불가** |
| 범은하 공동체 | **5.7%** / 0.1% / 0 | 일반 기물 **3명뿐** (에이든 · 비비안 · 유피토) — 1단계부터 3명 전원 필요 |
| 최고의 친구 · 캠핑 러버 · 은하 대스타 · 셰프 · 침투자 | 33~40% / 3.5~5.7% / 0 | 일반 기물 5명 → **6명(3단계) 불가** |

| 엔지니어 · 시간 여행자 | 21% / 6~8% / 1~1.5% | 단계가 2/3/4라 그나마 도달 |
- 리워크 표의 빈 특성 칸(＋)이 그대로라 특성 인원이 줄어든 영향이 크다.
- 도달 시 성공률이 높은 시너지: 셰프 2단계 80% (n=35) · 엘베스타드 2단계 72.7% · 제국 64% · 시간 여행자 62.7%.
- 도달해도 낮은 시너지: **침투자 2단계 14% (n=57)**, **엔지니어 1단계 이상 18.8%**.

### 비교 실험 (같은 시드 1000판)
- **포탑 제거**: 엔지니어 활성 런 18.8% → 15.1%. 포탑은 오히려 도움이 된다 → 엔지니어 부진의 원인은 **기물 쪽(재장전이 긴 명사수 위주)**.
- **침투자 순간이동 제거**: 성공률 변화 없음(28.5% → 28.5%), 그러나 **오디세우스 사망률 26.0% → 13.1%**, 로마니 40.4% → 32.6%. 기습 피해 이득과 원거리 기물 손실이 상쇄된다.

## 5. 사건
- 런당 사건 10.5회, 84종 중 83종 등장 (**기습 공연**은 0회).
- **연계 후속 사건 등장률이 1~2.6%** (귀항 0.1%, 기습 공연 0%). 시작 사건을 보고 → 표식 선택 → 남은 사건 노드에서 가중치 2.5/전체 ~70으로 뽑혀야 해서 거의 안 이어진다.
- **야전 진료소 · 정밀 검진**(기존 사건): 크레딧 -10에 출전 기물 전원 모든 메이저 +2 → 평균 영구 스탯 **+62.8**. 다른 선택지보다 압도적.
- 선택지 즉시 가치 상위는 대부분 "배신하고 크레딧"(사절단 위치를 판다 +22, 망명자를 넘긴다 +20, 입찰 공작 +20, 정전 회담 발전기 +25). 하위는 크레딧만 쓰고 보상이 확률·연계 뿐인 선택지(봉인 상자 -20, 수배서 매입 -15, 연료 바가지 -12). 사채업자 급전 +25는 대출 상환을 반영하지 않은 값.
- 같은 페이즈 기준선 대비 성공률 편차는 대부분 ±7%p 오차 범위 안. 눈여겨볼 것: 합창단의 초대장 -6.8%p (사이오닉 기물을 한 페이즈 빼는 비용), 헤드헌터 -6.0%p.

## 6. 기타
- **전술 위력이 페이즈 내내 15 안팎으로 고정** (P1 15.4 → P6 17.1). 적은 페이즈마다 강해지므로 지휘관 스킬 효율이 후반으로 갈수록 떨어진다.
- **권능 포인트가 남아돈다**: 런 종료 시 평균 27 (순례 비용 1~4). 신성력 상한 +50만 반복 구매해도 쌓인다.

## 7. 제안 (우선순위)
1. 범은하 공동체 일반 기물 확충, 또는 세력 단계를 3/5/7 → 2/4/6, 특성 빈 칸(＋) 채우기.
2. 물류망 사이오닉장을 보스 한정 또는 +10%로, 유닉스 생산 라인 P6 체력 하향.
3. 연계 후속 사건은 표식이 생기면 **다음 사건 노드에 고정 등장**.
4. 야전 진료소 정밀 검진: 출전 기물 무작위 2명 또는 +1로 하향.
5. 명사수(특히 엔지니어 계열) 재장전 · 탄창 상향, 침투자 순간이동은 근거리 기물만.
6. 전술 위력에 페이즈 보정 (예: 기본값 20 + 2 × 페이즈), 권능 획득량 절반 또는 순례 비용 상향.
