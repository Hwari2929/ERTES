## 사용자 요청

- 스페셜(데이터 키 `minor`)을 없앤다.
  - 디바인으로: 구닐라 · 데미우르고스 · 잉겔 · 자하라 · 재훤
  - 사이오닉으로: 비비안 · 빌 · 오르카 · 이든
  - 나머지 스페셜은 메이저로.
- 디바인 개편:
  - 성유물이 주요 위력에 맞는 주요 능력치를 준다 (초반 +3).
  - '봉헌'으로 성유물을 런 안에서 영구 성장시킨다. 단계마다 능력치 +3 · 신권 대행 위력 +20%p.
  - 축성은 대량 봉헌으로 바꾼다.
  - 권능 포인트에 비례해 자동으로 봉헌된다.
  - 순례는 제례(특정 신앙에 대량 봉헌) · 나눔(장비 재료 등)을 고르는 구조로 바꾼다.

### 지금과 새 구조

| 장치 | 지금 [사실] | 새 구조 |
|---|---|---|
| 신앙 · 신성력 · 신권 대행 | 신성력 100이면 신권 대행 | 그대로 |
| 권능 포인트 | 디바인마다 신성력 ÷ 25 + 1 (팀 전투당 상한 12) | 그대로 쌓임 (축성에 쓰는 화폐). 자동 봉헌은 권능을 깎지 않는다 |
| 성유물 | 신권 대행 그 자체, 능력치 없음 | 장착하면 주요 능력치 +3 (0단계) |
| '축성' (UI) = 강화 (코드) | 권능 25~40 → 다음 전투만 ×3 | 권능 → 봉헌 대량. 옛 ×3 (`enh`) 폐지 |

| 서약 증강 | 5등급마다 14종 | 유지. 축성 · 헌신 · 나눔의 서약 3종 손질 |

### 데이터 · 곡선 · 수치

- **저장**: 기물별 `UnitState.offer` (런 누계).
  - 성유물 id 가 겹칠 수 있어서다 [사실].
  - 화면에는 '성유물 봉헌 단계'로 보인다.
- **단계**: n단계 누계 = 12 × n(n+1)/2, 6단계까지 (12 · 36 · 72 · 120 · 180 · 252).
  - 주요 능력치: +3 → +21
  - 신권 대행 배율: ×1.0 → ×2.2
- **자동 봉헌**: 전투가 끝나면 출전한 디바인마다 2 + (그 기물이 번 권능 × 1). 대기 기물은 0.
  - 평균 기물은 의뢰 한 판에 약 176 (4단계), 잉겔처럼 신성력이 느린 기물은 약 88.
- **실측 [사실]** (디바인으로 바꿔 전투당 권능): 도로스 9.0 · 구닐라 7.9~8.2 · 재훤 6.1~6.9 · 자하라 2.3~3.4 · **잉겔 1.8~2.5** (셀레네 신앙에 회복이 없어 신권 대행 사용률 4~17%).
- **설정 키 제안**:
  - `CFG.offer`: { stat0 3, stat 3, act 0.2, step 12, max 6, perPower 1, floor 2 }
  - `CFG.consecrate`: { cost 20, gain 30, 페이즈당 1번 }
  - `CFG.rite`: { gain 40, choices 2 }
  - `CFG.alms`: { 보급 기준값 × 1 }
- **화면**:
  - 기물 상세: 봉헌 게이지 · '지금 → 다음' 칩.
  - 성유물 칸: 축성 단추 "권능 20 → 봉헌 +30".
  - 순례 화면: 고르기 카드 3장.
  - 전투 결과: '봉헌 +N'.
  - 교범: 봉헌 · 축성 · 순례 · 신성력 항목 새로.
  - 도감: 성유물 단계표.

## 6. 조사 중 찾은 기존 결함

- 사이오닉 전공 증강 칸 라벨이 5 · 10 · 15 · 20 으로 나왔다 (실제 4 · 8 · 12 · 16) → 2026-10-31 수정 (`src/app/unitparts.ts`).
