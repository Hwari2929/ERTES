## 0. 확정된 결정 (Q1~31 답변 요약)

- 시너지 **명사수·돌격가·전문가·참모단·성직자** 삭제. 앞의 셋은 전투 유형으로, 성직자는 디바인으로 흡수.
- 신앙·순례·축복 체계는 디바인 체계로 **교체**.
- 시너지는 **세력 1 + 특성 1~2**. 빈 특성 칸은 새 특성 4종(사용자 기획 예정)으로 채운다.
- 주요 능력치 5종(생명·전투·정신·방어·기동) 유지.
- 카이로 = 명사수, 자하라 = 돌격가. 나머지는 이 문서에서 배정.
- 피해 = 위력 × 계수 × (1 + 유형 피해량) × (1 + 속성 피해량) × 치명 × 방어. 속성(물리·정신·신성·전기)은 별도 축으로 유지.
- 지속 피해: 시전 시점 위력 고정, 치명 없음. **기술 피해는 치명 없음**(도노반 등 일부 특성·증강만 예외).
- 포지션은 무기에 종속: 근거리 사거리 1, 중거리 2~3, 원거리 4+. 배치 줄 제한 없음.
- 콤보: 기본 공격 1회 = 1스택, 무기별 N스택이면 다음 공격이 피니쉬. 대상 변경·행동 불능에도 유지.
- 탄창: 1발 = 공격 1회, 소진 시 재장전 동안 기본 공격 불가. (개정) 재장전 중에는 스킬도 쓰지 않는다 (쿨다운은 계속 돌고, 재장전이 끝나면 스킬부터). 재장전 중 제어 효과(기절 · 빙결 · 공포 · 감전)를 받으면 재장전이 처음으로 돌아가고, 제어가 걸려 있는 동안은 재장전이 멈춘다.
- 무기는 슬롯이지만 해제 버튼 없음(사실상 고정). 추후 교체 고려.
- **전술 위력** = 20 − 출전 기물 수 × 2 + Σ(지휘관마다 2 + ⌊정신력 × 0.25⌋). 지휘관 스킬은 전술 위력 계수. 아문센 등 일부 지휘관은 무기도 전술 위력.
- 합류 증강 유지. 스페셜은 합류 증강 + 스페셜 증강 **둘 다** 고른다.
- 마이너 성장 특성은 **런 내내 누적**. 성장폭이 작거나 조건이 까다로워 빌드업 감각이 있어야 함.
- 이성: 50에서 시작, 전투마다 초기화, 범위 −100~+100. 증감 규칙은 기물마다 다르다. 적(잡몹 포함)도 가진다.
- 디바인: 전투 중 게이지 **신성력**, 전투 후 런 자원 **권능 포인트**. 신권 대행은 전투당 1회 필살기. 신성력 수집에 상한.
- 신앙 11종: 황제 숭배, 아테나, 헤르메스, 아레스, 하데스, 제우스, 셀레네, 인간찬가, 지수추종, 과학지상주의, 시리우스 신학.
- 순례 노드: 디바인이 덱·대기실에 있으면 **첫 사건 노드 다음**에 고정 등장.
- 적: 전투 유형·포지션·무기는 전원, 전술 유형은 잡몹 포함 일부.
- 저장 호환은 끊는다(SAVE_VERSION ↑). 도감 기록은 유지.
- (2차 답변) 스페셜 스탯 성장은 자동 무작위. 기동력 → 사격·타격·재장전 속도 +1% 채택. 이성 선형 + 광폭 구간 채택.
- (2차 답변) 이중 세력 정리: 라르스 → 페트라, 잉겔 → 엘베스타드, 나디르 → 제국.
- (3차 답변) **모든 기물이 고유 신앙을 가진다.** 디바인이 아니면 효과가 비활성일 뿐이며, 신앙 표기는 전원에게 한다 (7장 표).
- (3차 답변) 라르스: 크레딧 10당 경호원 주요 능력치 +1pt, 100에서 상한. 본체 이자 상한 +2.
- (3차 답변) 프란체·로마니(지휘관)는 기본 공격 = 타격 위력, 스킬 = 전술 위력. 도노반·필리스(전문가)는 기본 공격 = 타격 위력, 스킬 = 기술 위력.
- (2차 답변) 아르곤 칭호·스킬을 이타카 뱃사공으로 교체 (게임 데이터 반영 완료: "이타카 최고참 도선사 · 뱃사공", 스킬 "망령권 작살").

## 1. 전술 유형별 성장 규칙

공통: 공명 등급이 오를 때마다 **모든 주요 능력치 +1**. 합류 시 기물 증강 1개.

| 전술 유형 | 능력치 선택 | 기물 증강 | 고유 추가분 |
|---|---|---|---|
| 메이저 | 3등급마다 2개 +3 | **3등급마다** (전용 + 메이저 공용 풀) | — |
| 마이너 | 3등급마다 2개 +3 | 5등급마다 | 성장형 특성 1개 추가 (런 누적) |
| 스페셜 | **매 등급** 추천 스탯 2종 중 무작위 1종 +3 (자동, 선택 창 없음) | 5등급마다 | 합류 시 스페셜 증강 1개 추가 선택 |
| 사이오닉 | 3등급마다 2개 +3 | 5등급마다 | 4등급마다 사이오닉 증강, 이성 체계 |
| 디바인 | 3등급마다 2개 +3 | 5등급마다 | 신앙 · 신성력 · 신권 대행 |

**메이저 공용 증강 풀 예시**: 지정 주요 능력치 +10pt / 사격·타격·기술 피해량 +20% / 치명 피해 +30% / 최대 체력 +15% / 재장전 속도 +25% / 콤보 피니쉬 피해량 +40% / 쿨다운 감소 속도 +20% / 지속 피해량 +30%.

## 2. 스탯 체계

| 주요 능력치 | 1pt당 (현행 + 추가안) |
|---|---|
| 생명력 | 최대 체력 +60, 회복 효율 +2% |
| 전투력 | 사격·타격 위력 +5, 치명 확률 +2% |
| 정신력 | 기술 위력 +5, 명중 +2%, 효과 명중 +3% |
| 방어력 | 방어도 +60, 효과 저항 +3% |
| 기동력 | 이동 속도 +4%, 회피 +2%, 사격·타격 속도 +1%, 재장전 속도 +1% |

전투 유형별 주력 스탯:

| 전투 유형 | 주력 |
|---|---|
| 명사수 | 사격 위력, 사격 속도, 재장전 속도, 명중, 치명 확률·피해 |
| 돌격가 | 타격 위력, 타격 속도, 명중, 콤보 피해량, 피니쉬 피해량, 치명 확률·피해 |
| 전문가 | 기술 위력, 효과 명중, 쿨다운 감소 속도, 기술 범위 |
| 지휘관 | 전술 위력(팀 공유) + 특수 규칙 |

새 피해량 항목(전부 % 합산): 사격 / 타격 / 기술 / 지속 피해량, 콤보 피해량, 피니쉬 피해량. 속성 피해량(물리·정신·신성·전기)은 별도로 곱한다.

- **높을수록**(최대 +100): 받는 정신·신성 피해 감소, 아군 지원(회복·보호막·버프) 효율 증가.
- **음수일수록**(최저 −100): 주는 정신 피해 증폭, 회복 효율 감소, 흡혈 부여.
- **−50 이하 = 광폭**: 초당 지속 피해를 받는 대신 피해 대폭 증가. 일부 기물은 광폭 진입이 핵심(조슈아 → 체사레).

| 기물 | 이성 증감 |
|---|---|
| 예레나 | 항밈 소거 사용 −8 / 아군이 스킬을 쓸 때 +2 |
| 히이로 | 점괘 길 +10, 흉 −10 |
| 나디르 | 스킬 −10 (기록에 읽힘) / 결정타 +6 |
| 제피로 | 초당 +1 (느긋함) / 염동 사용 −6 |
| 로마니 | 집행자 투척 −8 / 결정타 +10 |
| 조슈아 | 아군 체력이 줄 때마다 감소량 비례 − / 회복 시 + / −50 이하에서 체사레 |
| 레이첼 | 피니쉬 −5 / 주변 아군 보호 시 +4 |
| 오닉스 | 초당 −2 (합창이 이성을 깎는다) |

사이오닉 증강(4등급마다)은 사용자 명세를 받아 구현한다.

## 7. 디바인 · 신앙

**신성력**: 전투 중 0~100 게이지. 신앙 행동으로 획득. 전투당 **수집 상한 200**.
**신권 대행**: 신성력 100에서 전투당 1회 발동. 전투 유형별 4종에 신앙 수식이 붙는다.
**권능 포인트**: 전투 종료 시 그 전투에서 모은 신성력 ÷ 20 (최대 10).

## 8. 구현 메모 (1차)

- 적 기본 수치 배율: 체력 ×2.4, 위력 ×2.2 (리워크 전 2.0 / 2.0). 시뮬 40회 의뢰 성공률 38% (리워크 전 30%대).
- 적은 근접 = 콤보 4, 원거리 = 탄창 8 / 재장전 1.5초 무기를 자동으로 받고, 평균 피해가 이전과 같도록 계수를 보정했다. 모든 적은 이성 50으로 시작해 정신 피해를 받을 때마다 -4 (광폭 시 피해 +30%, 초당 지속 피해).
- 디바인 신성력: 신앙 행동 외에 초당 +2 기본 획득. 신권 대행 = 전투 유형 기본형 + 신앙 수식 (7장 표).
- 셰프는 이제 무기로 기본 공격을 하고, 전투 스킬이 요리다.
- 사이오닉 증강 5종은 임시(명징 / 심연 응시 / 이성의 방벽 / 광폭 제어 / 공명 증폭).
- 순례 노드: 입장 시 권능 +1. 권능으로 신앙 변경(3) · 수집 상한 +50(4) · 축복(2) · 크레딧 +3(1) · 공명도 4(1).

- (UI 피드백 반영) 전투·전술 유형은 시너지 칩과 다른 '클래스 표기'(글자)로, 시너지는 '시너지' 줄로 분리. 무기 · 특성 · 스킬 · 성장 · 이성 · 신권은 같은 모양의 능력 블록.
- 설명은 기본적으로 계수를 숨긴 요약(`src/data/brief.ts`). [상세 보기] 토글(단축키 D, 설정 저장)을 켜면 계수 · 메커니즘 원문을 보여준다.
- 시작 기물: 무작위 8명 후보 중 4명 선택.
