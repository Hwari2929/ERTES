# 사건 연출 작성 가이드

사건 본문과 선택 결과를 미연시(비주얼 노벨)식 대본으로 적는다. 규격은 `src/data/scene.ts`, 예시는 `src/data/scenes/pilot.ts` (시범 5편, 톤의 기준).

## 파일 구조

- `src/data/scenes/<묶음>.ts` 가 `<묶음>_SCENES: Record<사건 id, EventScene>` 와 `<묶음>_REG: SceneReg` 를 내보낸다.
- 새 NPC · 배경 · 배경음 · 효과음은 그 묶음의 `_REG` 에 등록한다 (공용 등록부 `scene.ts` 의 키와 겹치지 않게, 기존 키는 재사용 권장).
- 작성 도우미 (`./dsl`): `N(서술)`, `S(화자, 대사)`, `T(화자, 속마음)`, `SUB` (동적 조연 자리).

## EventScene

```ts
{
  cast: ['주연 기물 id', ...],          // 보유 여부와 무관하게 등장. 1~2명
  scene: [ ...본문 15~25줄, SUB ... ],   // SUB 는 본문 중간에 정확히 1번
  subs: { 기물id: [2~5줄], ... },        // 조연 후보 4~6명 (주연 제외)
  after: [ 선택지0 결과, 선택지1 결과, ... ], // 선택지 순서대로. 결과가 갈리면 { 키: [...], 키2: [...] }
}
```

- 결과가 확률 · 조건으로 갈리는 선택지는 키별 장면을 쓰고, 해당 선택지의 `apply` 안에서 분기마다 `api.outcome('키')` 를 호출한다 (기존 효과 코드는 바꾸지 않는다).
- 결과 장면에서 런마다 달라지는 이름(무작위 기물 등)은 `api.outcome('키', { 변수: 값 })` 으로 넘기고 텍스트에 `{변수}` 로 쓴다. 기물 이름은 그 파일의 이름 함수(`nm(u)`, `who(u)` 등)를 쓴다.
- 결과 장면이 필요 없는 선택지는 `null`.

## 줄 (Beat)

| 필드 | 용도 |
|---|---|
| `who` | 화자: 기물 id · NPC id. 없으면 서술 |
| `name` | 표시 이름 덮어쓰기 (`'???'`, `'라스무스 (덕트 밖)'`) |
| `think` | 속마음 독백 (`T()` 가 넣는다) |
| `face` | `base smile grin laugh serious angry sad surprise worried tired smug shy blank` |
| `at` | 화자 위치 `L C R` (처음이면 등장). 보통 주연 L, 상대 R, 조연 C |
| `stage` | 말하지 않는 인물 배치 `[{ id, at, face }]` |
| `exit` | 이 줄 뒤 퇴장 (`true` = 화자, 배열 = 지정) |
| `bg` · `bgm` | 배경 · 배경음 전환. 본문 첫 줄에 반드시 `bg` 와 `bgm` |
| `sfx` | 효과음. 장면당 2~4개 정도, 남발 금지 |
| `fx` | `shake flash fade dark glitch`. 결정적 순간에만 |

## 문체

- **서술은 3인칭 현재형**("~한다", "~이다"). 결과 장면은 과거형도 허용. 문장은 짧고 구체적으로. 감각(소리 · 냄새 · 온도 · 빛)을 하나씩.
- **독백은 주연의 속마음**(1인칭, 반말 독백체). 그 인물의 과거 · 신념 · 버릇과 사건을 잇는 한두 문장. 주연 외 인물의 독백은 드물게.
- **대사는 따옴표 없이** 적는다. 인물마다 말투를 지킨다 (로어 문서의 인용구 · 말버릇 · 존댓말 여부).
- **한 줄 = 1~3문장.** 화면 한 장에 들어갈 호흡. 본문 15~25줄, 결과 3~6줄.
- **주인공**은 `{pc}` (현재 '지휘관')로만 가리키고 대사를 주지 않는다. 인물들이 {pc}에게 말을 걸 수는 있다 (결정은 {pc}에게 맡긴다는 식으로 선택지로 넘긴다).
- 본문 마지막 2~3줄은 **선택지로 자연스럽게 넘어가는 대사**로 끝낸다. 선택지의 내용(효과)을 인물의 말로 암시하되 수치는 말하지 않는다.
- 기존 `text`(요약)의 사실 · 고유명사 · 인용 대사는 모두 장면 안에 살린다. `text` 필드 자체는 바꾸지 않는다 (도감 · 문서용 요약).
- 유머는 인물에서 나온다(버릇 · 집착 · 관계). 설명조 금지, 말장난 과용 금지.
- 로어와 모순되는 설정 금지. 로어에 없는 작은 설정(과거 일화 등)은 써도 되지만 최소한으로, 작업 보고에 목록으로 남긴다.

## 조연 (subs)

- 사건 주제와 가장 잘 엮이는 인물 4~6명. 로어 문서가 있는 인물 우선.
- 2~5줄의 짧은 끼어들기: 조연의 한마디 → (주연 · NPC 의 반응) → 퇴장. 조연 없이 읽어도 본문이 자연스러워야 한다.
- 같은 인물을 여러 사건의 조연으로 쓰는 건 괜찮지만, 묶음 안에서 한 인물이 5회 넘게 나오지 않게.

## 확인

- `npx tsc --noEmit -p .` 통과.
- 화자 id 는 `UNIT_BY_ID` 의 기물 id 이거나 등록부의 NPC id.

## 읽히는 글 (2차 지침 · 이 절이 위 문체 규칙보다 우선)

지금까지 쓴 장면의 가장 큰 문제: **캐릭터 시트 · 로어 문서의 문장을 그대로 옮겨 붙였다.** 처음 읽는 사람은 "객례법 제1조"가 뭔지, 그 인물이 왜 그 말을 하는지 모른다. 아래를 지킨다.

### 1. 처음 읽는 사람 기준으로 쓴다
- 플레이어는 로어 문서를 읽지 않았다. **고유명사 · 설정어는 장면 안에서 뜻이 대충 짐작되게** 쓴다. 처음 나오는 설정어에는 그게 뭔지 한 줄로 풀어 주거나(인물이 투덜대며 설명, 상대가 되묻기), 아예 쉬운 말로 바꾼다.
- 한 장면에 새 설정어는 **많아야 2~3개.** 나머지는 빼거나 일반 명사로 바꾼다 ("헬레니우스 동맹 객례법 제1조" → "동맹 항구는 손님한테 어디서 왔는지 안 묻는대").
- 사건의 상황(누가, 뭘 원하고, 왜 지금 결정해야 하는지)은 **본문 앞 1/3 안에** 독자가 이해해야 한다. 선택지에 도착했을 때 "그래서 뭘 고르라는 거지?"가 나오면 실패.
- 인물의 과거를 꺼낼 때는 **설정 문장이 아니라 장면 하나**로: "교단에 붙잡혔을 때" (X) → "화물칸 바닥에 웅크려서, 문 열리는 소리만 기다리던 그 사흘" (O).

### 2. 독백은 '그 사람 머릿속 목소리'다
- 독백은 해설이 아니다. **지금 이 순간 그 인물이 실제로 할 법한 생각**: 투덜거림, 딴생각, 자기 합리화, 걱정, 들뜸, 츳코미.
- 조금 오타쿠 같아도 좋다 — 라노벨 · 미연시 주인공의 속마음처럼 **과장된 감정, 자기 자신에게 하는 츳코미, 괄호 속 속마음, 뜬금없는 비유, 말줄임**을 쓴다. 단 그 인물의 성격 범위 안에서 (차분한 인물은 건조한 자조로, 들뜬 인물은 폭주로).
- **공감 가능해야 한다**: 누구나 겪는 감정(귀찮음, 민망함, 배고픔, 남 눈치, 괜히 착한 척하고 싶은 마음, 무서운데 안 무서운 척)에 사건을 붙인다.
- 독백 한 줄에 정보 하나 + 감정 하나. 교리 · 법조문 · 수치 인용 금지.

나쁜 예 (설정 복붙):
> T('iris', '객례법 제1조. 항구는 손님의 출신과 신앙과 죄를 묻지 않는다. …이 사람, 제대로 알고 왔다.')

좋은 예 (머릿속 목소리):
> T('iris', '와, 이타카 규칙까지 알고 왔어. 손님이면 어디서 왔든 안 묻는다는 거. …이거 거절하면 나 헤르메스님한테 혼나는 거 아냐?')
> T('iris', '(침착하자 이리스. 신관답게. 신관답게…) 아니 근데 저 장부 진짜 두껍다.')

### 3. 캐릭터성 = 말버릇이 아니라 반응
- 말버릇 · 존댓말 여부는 지키되, **캐릭터성은 '같은 상황에 이 사람만 보이는 반응'**으로 드러낸다. 같은 위기에 누구는 돈부터 세고, 누구는 도망칠 길부터 보고, 누구는 배고프다고 한다.
- 인물 대사에 프로필 소개를 넣지 않는다 ("나는 ○○ 출신 △△다" 금지). 상대가 이미 아는 사이다.
- 대사끼리 **주고받는 맛**: 한 사람이 길게 설명하고 끝나지 말고, 끊기고, 되묻고, 딴소리하고, 츳코미가 들어온다.

### 4. 점검표 (장면마다)
- [ ] 로어 문서 문장을 그대로 옮긴 줄이 없다.
- [ ] 처음 보는 사람도 상황 · 갈등 · 선택의 의미를 안다.
- [ ] 주연 독백이 2~4줄, 그중 하나 이상은 웃기거나 찡하거나 민망하다.
- [ ] 새 설정어 3개 이하, 각각 뜻이 짐작된다.

## 3차 지침 (이 절이 위의 모든 지침보다 우선)

2차까지 고친 뒤에도 남은 문제: **모든 인물이 같은 사람처럼 말한다.** 차분하고, 통찰을 말하고, 상황을 곱씹는다. 그리고 속마음이 너무 많다. 아래 네 가지를 지킨다.

### 1. 그 사람처럼 말한다 (docs/VOICES.md 를 먼저 읽는다)
- 인물마다 말투 · 텐션 · 관심사가 다르다. **가벼운 인물은 끝까지 가볍게.** 유피토 같은 통통 튀는 인물이 무거운 이야기 · 깊은 통찰 · 상황에 대한 고뇌를 말하면 캐릭터가 죽는다. 그런 인물은 신나서 엉뚱한 데로 새고, 들뜨고, 실수한다.
- 연륜 있는 인물도 종류가 다르다. 투덜대는 노장, 능글맞은 장사꾼, 말수 적은 장인, 잔소리꾼 — **"깊이"를 경구로 표현하지 않는다.** 행동 · 짧은 한마디 · 습관으로 보여 준다.
- 대사는 **평범한 구어**: 짧고, 끊기고, 되묻고, 딴소리한다. 문어체 · 잠언 · "~라는 것이다" 식 정리 금지. 누가 읽어도 "아 이 사람 이런 사람이구나"가 대사 두세 줄 안에 보여야 한다.
- 대사 한 줄 점검: 이름표를 가리고 읽어도 누가 한 말인지 맞힐 수 있나? 다른 인물 아무나 해도 되는 대사면 다시 쓴다.

### 2. 속마음(T)은 거의 쓰지 않는다
- 기본은 **0줄.** 꼭 필요할 때만 장면당 최대 1줄, 짧고 가벼운 것(츳코미 · 딴생각 한마디)만.
- 서술(N)도 철학 · 감상 · 의미 부여를 하지 않는다. **보이는 것 · 들리는 것 · 하는 행동**만 짧게.
- 감정은 대사와 행동으로: "…그래서, 내 몫은?" / 말없이 잔을 내려놓는다.

### 3. 상황을 먼저 깔아 준다
- 장면 첫 3~6줄 안에 **어디서, 누가, 무슨 일로, 지금 뭐가 문제인지**가 보여야 한다. 갑자기 사건 한가운데로 뛰어들지 않는다.
- 방법: 누군가 도착해서 상황을 묻는다 / 인물이 투덜대며 설명한다 / 짧은 서술 한두 줄. 선택지에 도착했을 때 **각 선택이 무엇을 뜻하는지** 독자가 안다.
- 결과 장면(after)도 원인과 결과가 이어지게: 무엇을 골랐고 그래서 무슨 일이 생겼는지.

### 4. 로어는 재료지 대사가 아니다
- 로어 문서 문장 · 설정어 · 프로필을 대사에 옮겨 붙이지 않는다. 로어는 **그 인물이 이 상황에서 어떻게 반응할지 정하는 근거**로만 쓴다.
- 로어를 바탕으로 **새로운 작은 이야기**를 만든다: 그 설정 때문에 생기는 소동, 습관, 오해, 사소한 갈등. 설정을 읽어 주는 장면은 실패다.
- 새 설정어는 장면당 1~2개, 뜻이 대사로 짐작되게.

### 점검표 (3차)
- [ ] 이름표를 가려도 화자를 맞힐 수 있다 (인물별 말투가 뚜렷하다)
- [ ] 가벼운 인물이 무거운 말을 하지 않는다 / 경구 · 잠언 · 통찰 정리 대사가 없다
- [ ] 속마음 0~1줄
- [ ] 첫 몇 줄 안에 상황이 보이고, 선택지의 의미가 분명하다
- [ ] 로어 문장 복붙 · 설정 낭독이 없다
