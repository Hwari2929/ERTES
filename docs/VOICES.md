# 인물 말투 시트 (VOICES)

> **⚠ 숫자는 반드시 아라비아 숫자로 쓴다.** 수량 · 횟수 · 시각 · 나이 · 서수 모두: '세 잔' → '3잔', '백열두 번째' → '112번째', '새벽 두 시' → '새벽 2시', '사흘' → '3일', '셋째 줄' → '3번째 줄'.
> 예외는 수량이 아닌 관용 표현뿐이다: '한 번 더', '한 잔 하자'의 '한', '첫', 어림수(한두 · 두세 · 서너), 높임 '두 분', 친족 · 나열 순서 단어(둘째 딸 · 첫째, 둘째, 셋째). `npm run check` 의 숫자 표기 검사(tests/number_check.ts)가 막는다. 일괄 변환: `python3 scripts/numfix.py --apply <파일>`.
>
> **⚠ 대본에서 새로 생긴 인물 설정은 `lore/인물/확장/<이름>.md` 에 기록한다.** 출처(대본 id · 파일)와 원본 시트와의 관계(원본 확장 · 원본 해석 · 새 설정)를 적고, 원본 시트 · 세계관 문서와 어긋나지 않는지 그 문서 머리의 체크리스트로 확인한다 (`npm run check` 의 확장 설정 검사가 출처 존재 · 금지 설정 충돌을 본다).

장면 작성 전에 읽는다. `docs/SCENES.md` 3차 지침의 "그 사람처럼 말한다"를 인물별로 풀어 놓은 문서다.
예시 대사는 **톤 견본**이다. 그대로 복붙하지 말고 같은 결로 새로 쓴다. 로어 문장 · 경구 · 통찰 정리 대사는 금지.
`(추정)` = 로어 문서가 없거나 얇아서 칭호 · 인용구 · 기술 · 기존 장면에서 추론한 부분. 로어가 생기면 그쪽을 따른다.

## 에란테스 공용 설정 메모

**장소**
- **에란테스 바는 지상에 있는 진짜 바다.** 함선 안에 있지 않다. 행성 위 거리에 면한 엄청나게 큰 실내 바로, 여러 층의 발코니, 길게 휜 카운터, 끝없는 술병 진열장이 있고 거리 쪽 창으로 아침 해가 든다(프란체는 그늘로 피한다). 에란테스의 지상 거점(로어 표현으로는 본부 · '바 지부')이고, 외부 손님도 받는다(제피로 · 클로에는 손님으로 왔다가 입단). 총 관리인 겸 바텐더는 에이든.
- **함대 · 함선은 따로다.** 의뢰가 생기면 함대가 현장 근처에 정박하고 셔틀로 내려간다. 함선 공간은 함교 · 화물칸 · 정비 덕트 · 식당 · 주방 · 기관실 · 격납고 · 휴게실이다. 함선 안 술자리는 '바'라고 부르지 않는다(식당 · 휴게실). 바에 남은 사람은 통신(홀로그램 창)으로 현장과 이어진다(튜토리얼 방식).
- **바 당직**: 단원들이 돌아가며 바를 본다. 당직마다 버릇이 있다. 게베크 = 특제 핵융합볶음면(에이든 · 엘레니만 완식), 웨스트 = 맥주 · 시드르 · 브런치만(버터+꿀 스테이크), 카이로 = 칵테일은 잘 말지만 브런치 없음, 조슈아 = 술 없이 메뉴 4개 고정(스테이크 · 캐슈넛 샐러드 · 오일 파스타 · 당근 주스), 체사레 = 그냥 자리에 없음, 자하라 = 술 대신 차 · 음료만, 비비안 = 가니시 각도에 집착(손재주는 별로), 오르카 = 평이 아주 좋음, 클로에 = 분위기 무르익으면 졺, 히이로 = 한 번 섰는데 손님 3배, 테무르 = 당직 금지(얼음 만질 때마다 고양이 비명), 에이든 = 메뉴판에 없는 메뉴 수백 종.

**시간 · 아문센**
- 현재는 은하력 562년.
- **아문센은 튜토리얼 시점에 은퇴했다.** 가방 하나, 쪽지 한 장(테세우스의 배 수수께끼), 땅콩버터 빈 병을 남겼다. 사건은 아무 시점에나 놓일 수 있으므로 → 대사로 은퇴 여부를 확정하지 않는다 / 아문센이 나오면 지휘 · 명령이 아니라 참견 · 술자리 · 옛날 얘기로만 / 결정은 언제나 {pc}가 한다.
- 아문센 호칭: 단원들 '단장(님)', 게베크 '단장 양반', 바르가 · 코브 '영감', 레이첼 '아빠'.

**주인공**
- **레이첼 = 주인공 = 사건 장면의 `{pc}`.** `src/data/scene.ts` 의 `PC_NAME = '지휘관'` 이라 `{pc}`는 화면에 '지휘관'으로 찍힌다. 화자 `'pc'`의 스탠딩은 레이첼 그림이다(`src/main.ts` advSpeaker). 튜토리얼에서 레이첼이 아문센의 지휘관석을 물려받는다.
- 그러므로 **한 장면에서 `rachel`과 `{pc}`를 다른 사람처럼 쓰지 않는다.** 지금 16개 장면이 레이첼을 따로 말하게 하면서 `{pc}`도 따로 부르고 있고, 그중 2곳(story_a `sa_rachel_fridge`, story_b3 `sb_double`)은 레이첼이 `{pc}`에게 말을 건다. 모순이다. SCENES.md 1차 규칙("`{pc}`에게 대사를 주지 않는다")과 레이첼 대사를 어떻게 맞출지는 따로 정해야 한다.
- 레이첼 호칭: 단원들 '지휘관님', 현장 동기 · 가족 '레이첼', 테무르 '주인님', 에이든 '핫초코 곱빼기 손님'. 로어 일부엔 '레이첼/라파엘'로 병기되어 있다.

**세계 공통**
- **계약**: 단원은 아문센과 계약해서 늙지 않고, 죽어도 되살아난다(프란체 "2시간쯤 뒤 부활", 아문센 "체사레는 죽어도 하루쯤이면"). 농담 소재로는 써도 되지만 원리를 설명하지 않는다(아무도 모른다).
- **정장 규정**: 아문센이 에란테스 정장을 강요해서 다들 저항한다. 미리내 = 입었다 벗었다, 도노반 = 후드티 위 재킷 + 후드 끈 넥타이, 제피로 · 나디르 = 와이셔츠만(아문센: "그건 속옷이네"), 유피토 = 공식 석상만, 엘레니 = 망토처럼 걸침.
- **엘베스타드 본가**는 네오사이트의 저택이다. 시그문드 · 구닐라 · 라스무스 · 맥스 · 밍키의 원래 자리다. 본가에 사는 가족은 올리버 하나뿐. 이들이 함선 · 바에 나오면 따라왔다 · 찾아왔다는 이유를 한 줄 깔아 준다. 가주 = 라르스(지빌 분기). 아문센 · 올리버 · 비외른 · 레이첼 = 비페르소 분기. 잉겔 · 스카디 = 라르스의 딸.
- **가족 관계**: 빌 → 클로에(친딸) · 도노반(양자, 클로에의 오빠) / 웨스트 → 윈터(딸, 비비안의 지도교수) / 게베크 ↔ 지나(부부, 아들 셋, 막내 유리) / 라르스 → 잉겔 · 스카디 / 아문센 → 레이첼(양녀), 라르스(사촌 동생) / 로마니 → 카일(가문의 실종 가주, 회수 대상. 성도회 문서 · 기물 소개상 같은 사람이지만 둘의 과거는 대사로 확정하지 않는다).
- **구면**: 예레나 · 도노반 · 클로에(보안위원회), 오르카 · 린디웨 · 프란체 · 클로에(페트라. 클로에는 프란체의 직속 후임이자 산업 스파이였다), 카이로 · 비앙카(나디르를 구해 왔다), 이리스 · 오디세우스(스파르타 전선 동료), 웨스트 · 아문센(연합군 시절).
- **반복 개그(써도 됨)**: 땅콩버터 도둑, 프란체 머리에 붙는 불, 똥 · 방귀 얘기에 웃음이 터지는 엘레니, 냉동고를 못 만지는 테무르, 불붙는 게베크의 트림, 필리스의 '긴급 조달', 이름을 안 외우는 에이든, 예레나의 급여 분할 공제, 라르스의 탈모 소문, 웨스트의 이불 일광 건조.
- **기물 칭호와 로어가 어긋나는 인물**: 장면에서는 기물 칭호를 따르고, 어긋나는 디테일은 꺼내지 않는다. 오디세우스(로어 = 이타카 용병왕 38세, 항구를 3일 이상 못 비움 / 기물 = 20년 만에 귀환한 정찰병), 카부라야(로어 = 은둔 중인 호이슌가 21세 막내, 버추얼 아이돌 괴담 / 기물 = 리스크관리본부장), 마오(로어 = 네코마츠리 CEO, 고양이 환수, 실물 미공개 / 기물 = 호이슌 홀딩스 회장), 팔콘(틀-페트라 = 개척개발부장 / 기물 = 레일건 시험 사수), 빌(틀 = 제2위원장 / 기물 = 위원), ISSAC(기물 칭호 '연합 생체 실험체'는 그의 표면 설명이다. 정체는 아래 항목). 스카디는 사용자 확인으로 칭호를 '자산관리부 인재격려실장'으로 고쳤다.

## 층 (표면 · 이상 · 실재) — 바 허브 2차

인물은 표면 · 이상 · 실재, 3개 층으로 쓴다. 대사 · 만담 · 대본마다 층 태그를 단다 (`src/data/bar/*` 의 `layer`: `s` 표면 · `i` 이상 · `r` 실재).
- **표면**: 말버릇 · 소재 · 취미 (스콜치, 꿀, 가챠…). 대부분의 만담이 여기다. 같은 소재를 계속 꺼내면 캐릭터가 반복 개그 하나로 줄어든다 → `npm run check` 의 소재 검사가 경고한다 (docs/MOTIFS.md).
- **이상**: 가치 · 목표 · 입장 (용병의 윤리, 기업국가, 승천을 어떻게 보나). 토론 · 정치 틀에서 인물마다 입장이 갈리게 쓴다.
- **실재**: 상처 · 방어기제 (lore/인물/*.md 의 '실재와 자아'). **고백하지 않는다. 새어 나오게 쓴다.** 아래 각 인물의 '새어 나오는 방식(트리거 → 반응)'을 쓴다: 트리거 상황을 깔고, 인물은 그 반응만 한다. 해석 · 설명 · 독백 금지. 상대가 짚어도 인물은 인정하지 않는다.
- 노출 비율: 실재 층은 바 노출의 약 10%. 실재 층은 심야 장면이고, 그 인물과의 관계가 쌓인 뒤에 열린다 (바에서 말 건 횟수 + 함께 출전한 런 수, src/ui/bar.ts `DEEP_BOND`).
- '새어 나오는 방식'은 로어 문서(lore/인물)가 있는 28명만 적었다(예외: ISSAC — 사용자가 정체를 직접 알려 줘서 적었다). 로어가 없는 인물(레이첼 · 잉겔 · 스카디 · 비외른 · 시그문드 · 구닐라 · 라스무스 · 밍키 · 팔콘 · U-404 · 카부라야 · 레이카 · 마오 · 귀공자 · 빌 · 윈터 · ISSAC · 이든 · 카일 · 도로스 · 데미우르고스 · 지나 · 오디세우스 · 아르곤 · 포티니 · 테르모필레 · 오닉스 · 루스 · 사르마)은 비워 둔다. 지어내지 않는다.

## 근거와 추정 (바 허브 4차 · 말투 재점검)

말투는 아래 순서로 정한다. 위쪽이 원본이고, 아래쪽은 원본에서 끌어낸 해석이다. 어긋나면 위쪽을 따르고 아래쪽을 고친다.
1. **원본**: lore/ 의 인물 시트 · 세력 · 지역 · 틀 문서, 사용자가 대화로 준 인물 시트 · 키워드 · 시안 선택.
2. **기물 데이터**: 칭호 · 소개 문구 · 시너지(src/data/roster*.ts). 시너지 배정은 사용자가 정했고, 칭호 · 소개 문구는 작성 보조가 쓴 것이 많다.
3. **이 문서의 '(추정)'**: 말버릇 · 텐션 · 예시 대사.

- 로어 문서가 없는 인물은 각 항목의 **근거** 줄을 먼저 읽는다. 근거에 없는 말버릇, 느낌표 연발, 반복 개그로 개성을 부풀리지 않는다. 근거가 얇으면 담백하게 쓴다.
- '(추정)'으로 적힌 말버릇은 장면당 1번 이하로 쓴다. 매 대사에 넣으면 그 인물이 개그 하나로 줄어든다.
- 사례 (4차 재점검): 린디웨는 'A요! B요!' 연타 → 시트의 '밝고 속도감 있되 협상에선 문장이 짧아지는' 30세 실무자로. 히이로는 짧게 끊는 단답 → 시트의 '느리고 나른한 말, 미소 · 침묵으로 답함'으로. 테무르는 조사를 뺀 원시인 말투 → 시트 인용구의 거친 구어체로(문맹이지만 우둔하지 않다). 프란체는 '선크림' 개그를 지우고 시트의 '빛에 타는 걸 알면서 낮 커피' · '110년 전 크림슨 예법'으로.
- 고향(공통 질문 '고향은 어디야?'): lore/인물 시트의 인적사항 · lore/_틀/틀-연합.md 출신 인물 표 · lore/지역 문서와 맞춘다. 근거가 없는 인물(사르마 · 시그문드 · 구닐라 · 라스무스 · 카부라야 · 도로스 등)은 지어내지 않고 얼버무린다. 지어낸 부분은 확장 문서에 적는다.
- 사례: 비외른은 '우렁찬 반말 + 매 대사 청구 개그'로 적혀 있었지만, 원본(구호조장 · 바이킹 스타일 의료인 · 덩치 큰 중년)과 기물 소개 문구는 차분한 쪽이었다. 그래서 '낮고 짧은 반말 · 의료인 · 청구는 담담한 절차'로 고쳤다(아래 항목).

## 확장 설정 (바 허브 4차)

대사 · 만담 · 대본에서 새로 생긴 인물 설정은 `lore/인물/확장/<이름>.md` 에 모은다 (형식 · 관계 구분은 docs/SCENES.md 3차 지침 5).
- 인물 대사를 쓰기 전에 이 시트와 함께 그 인물의 확장 문서를 읽는다. 이미 적힌 설정(가족 사진 · 단골 메뉴 · 연락하는 사람 등)과 어긋나게 쓰지 않는다.
- 로어 문서가 없는 인물도 확장 문서는 만든다 (원본 시트: 없음). 다만 '새어 나오는 방식'(실재 층)은 여전히 지어내지 않는다. 확장 설정은 표면 · 이상 층의 사실만 적는다.
- 위 '금지' 항목은 확장 문서 머리의 '금지 설정:' 줄에 핵심어로 옮겨 둔다. `npm run check` 가 항목 문장에 그 핵심어가 들어가면 막는다.
