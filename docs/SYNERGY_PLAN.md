## 새 시너지 효과 (사용자 안)

### 스텔라레이서 (세력 2/4/6)
- 소속 기물 기동력 +5 / +11 / +24.
- 활성화 시 전투 시작에 성간 경기장에서 이탈한 비행선이 추락해 적 전체에 n% 고정 피해. **(n 미정)**
- 4단계: 비행선 추락 20초마다 재발동 · 6단계: 10초마다.

### 보안위원회 (세력 2/4/6)
- 소속 기물이 받는 모든 피해 -10% / -20% / -30%, 정신 피해는 추가로 -15% / -20% / -30%.
- 소속 기물이 가진 해로운 효과 1개당 쿨다운 감소 속도 +10% / +20% / +50%.

### 호이슌 홀딩스 (세력 2/4/6 ?)
- 소속 기물 정신력 +5 / +11 / +24.
- 페이즈 중간에 [투자] 노드 추가: 크레딧으로 문장 구입, 호이슌 전용 버프, 특정 아군의 고유 증강 구매, 투자 후 다음 페이즈에 불려 받기 등.

### 분해자 (특성 2/4/6/8)
- 소속 기물의 화학 피해량 +10% / +25% / +50% / +100%.
- 소속 기물이 기본 공격 · 기술로 적을 공격하면 자신 최대 체력 5%의 추가 화학 피해 + 100% 고정 확률로 [부식] 중첩 (받는 화학 피해 +10%p, 최대 5중첩).
- 4단계: [부식] 최대 +2, [부식] 대상을 공격하면 피해의 20% 회복 · 6단계: 추가 화학 피해 최대 체력 10%, [부식] 최대 +2 · 8단계: 추가 화학 피해 15%, [부식] 최대 +4.

### 모략가 (특성 2/4/6/8)
- 소속 기물 효과 명중 +25 / +50 / +75 / +100%.
- 소속 기물이 적에게 해로운 효과를 걸면 기본 75% 확률로 [암운] 중첩: 초당 대상 최대 체력 0.1% / 0.25% / 0.5% / 1% 고정 피해, 최대 99중첩.

### 전도체 (특성 2/4/6/8)

- 소속 기물이 기본 공격 · 기술로 적을 공격하면 25% 고정 확률로 1 / 2 / 3 / 3칸 이내 적에게 최대 1 / 2 / 4 / 8회 연쇄 전기 피해. 개별 피해 = 사격 · 타격 · 기술 위력 중 가장 높은 값의 20%.
