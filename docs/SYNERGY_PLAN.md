## 구조 변경
- 세력 7 → 11: 보안위원회(SEC) · 스텔라레이서(STL) · 호이슌 홀딩스(HOI) 추가, 시간 여행자(TIME)를 특성에서 세력으로 이동.
- 특성 11 → 14: 모략가(SCHEME) · 분해자(DECOMP) · 전도체(COND) · 수호자(GUARD) 추가.
- 기물 46 → 57: 비외른 · 지나 · 포티니 양 · 카부라야 · 빌 · 윈터 · ISSAC · 이든 · 레이카 0호 · 마오 · 스카디 (`src/data/rosterF.ts`).
- 증표 규칙: 연합 · 제국 · 동맹 · 페트라 · 성도회 · 보안위원회 · 스텔라레이서는 증표를 단 출전 기물이 없으면 인원이 넘쳐도 최종 단계 직전으로 묶인다 (`synergyCounts`).
- 범은하 공동체 1~7: 옛 "세력 수 비례 + 다른 세력 인원 보태기" 규칙 삭제. 출전한 공동체 기물마다 모든 아군에게 선물, 공동체 기물은 2배, 단계 배율 ×1 / 1.25 / 1.5 / 1.75 / 2 / 2.5 / 3.

- 호이슌 활성 시 페이즈 중간 노드에 자동 삽입. 상품 수 3 / 4 / 5, 가격 ×1 / 0.85 / 0.7 (단계별).
- 상품: 호이슌 펀드(맡긴 크레딧 ×1.5 / 1.8 / 2.5 를 다음 페이즈 시작에 정산) · 문장 매입(3개 중 1) · 전략 자금 집행(이번 페이즈 호이슌 기물 피해 +35%, 쿨다운 감소 +25%) · 인재 영입 패키지(무작위 아군의 고유 증강 즉시 획득) · 정크 본드(50%로 ×4).
