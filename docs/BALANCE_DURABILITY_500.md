# 내구도·역경 후속 패치 — 덤비 고난 500판 짝 비교 (봇 표기 정정)

## 2026-10-20 정정

**이전 보고에서 실행 봇을 철수라고 잘못 표기했다. 실제 두 조건 모두 덤비다.** 실행 명령에 `bot=chulsu`가 없었고, `tests/balance.ts` 기본값은 `dumbi`다. 원자료 1,000판 전체에서 `runs[].ins.bot == "dumbi"`, `ins.areas == []`를 확인했다. 0.2%를 철수 승률이나 철수의 시너지 운영 결과로 사용하면 안 된다.

수치와 전투 기록 자체는 덤비의 결과로 유지한다. 이는 철수의 최신 성능을 검증한 실험이 아니다. 이 정정은 게임 수치를 변경하지 않는다.

## 결론

**역경 급사는 크게 줄었지만 최종 클리어율 상승은 확인하지 못했다.** 직전 PR 버전과 후속 패치를 같은 500시드로 각각 측정했고, 두 조건 모두 1판(0.2%)을 클리어했다. 평균 도달 페이즈는 2.694 → 2.978, 4페이즈 도달은 32 → 92판으로 개선됐다.

이 실험은 덤비를 사용했으므로 예전 철수 2단계 승률 29.8%와 비교할 수 없다. 1페이즈 보급, 전기 등 4속성 규칙 변경, 역경 적의 무작위 3장비 등을 넣었던 **직전 PR 시험판**이다. 해당 시험판은 이번 동일 500시드 측정에서 이미 0.2%였다.

## 적용 사항

| 항목 | 직전 PR | 후속 패치 |
|---|---|---|
| 역경 조우 계수 | 1.3 | 1.25 |
| 고난 이상 역경 적 장비 | 3개, C/G/A/L 각 25% | 3개, C/G/A 각 1/3, 전설 제외 |
| 역경 적 개조부품 | 기존 확률 | 유지 |
| 수호자 도발 기반 경감 | 없음 | 4·6수호자: 도발 계수 1당 5%, 8수호자: 10% |
| 연합 전투 후 추가 공명도 | +1/+2/+3/+5 | +2/+3/+4/+10 |
| 의무관 모든 아군 최대 체력 | +6/+12/+18/+24% | +10/+20/+40/+60% |
| 생명력 1당 체력 | 120 | 138 (+15%) |
| 방어력 1당 방어도 | 60 | 69 (+15%) |

- 1페이즈 보급 2회, 재훤·포티니 변경, 비물리 4속성 치명타 금지·기본 피해 ×1.25는 직전 PR과 동일하다.
- 장비 3개는 유지하며 전설만 후보에서 뺐다. 개조부품을 장비 슬롯의 대체 후보로 넣거나 모듈을 확정 지급하지 않았다. 모듈 장착은 기존 별도 확률을 따른다.
- **보스 노드의 전설 장비 규칙은 바꾸지 않았다.** 이번 장비 제한은 고난 이상 역경 및 같은 조우 생성 경로를 쓰는 도전 대상이다.
- 수호자 새 경감은 **수호자 자신**에게 적용한다. 소수점 도발 계수·장비·은신 등 현재 `provMult` 값에 따라 동적으로 계산하며, 기존 경감 상한 80%를 따른다. 기존 8수호자의 15% 피해 경감과 방어도·추가타 효과는 유지한다.
- 새 수호자 경감은 고정 피해와 직접 체력 비율 피해에도 적용한다. 이미 경감된 공유 피해에 다시 적용하지 않는다.
- 역경 계수는 기존 `CFG.adversityMult`를 1.25로 바꾼 것이다. 기존 엔진 규칙상 체력 ×1.25, 조우 피해 배율은 `encDmgMult(1.25) = 1.125`다. 일반 전투는 칸별 `1 + 0.04 × step`을 쓰므로, 같은 칸의 일반 전투 전체 수치에 일괄 ×1.25를 곱한 구현은 아니다.

### 적 수치·예상 환산 표시

적의 실제 체력·방어도는 적 정의와 페이즈 배율로 계산되므로 이번 아군 메이저 환산 상향에 맞춰 적 본체를 다시 올리지 않았다. 아군과 같은 계산을 사용하는 소환물, 기사, 장비의 메이저 가산 등은 새 환산을 자연스럽게 따른다.

현재 적 예상 공명 등급은 공격 위력으로 정하며, 체력은 같은 등급 아군 평균 대비 배수로 따로 표시한다. 그 아군 기준값은 `computeStats`를 사용하므로 새 체력 환산을 자동 반영한다. 공격 환산은 바꾸지 않아 예상 등급 숫자가 일괄 오르지 않고, 상대 체력 배수는 새 아군 기준에 맞춰 달라진다.

## 다음 판단

1. **급사 완화 목적은 관측 지표에서 달성됐다.** 특히 전설 장비가 줄줄이 붙던 역경 구간의 단기 패배가 감소했다.
2. **고난 클리어 밸런스가 해결됐다고 볼 수 없다.** 보스 전설 규칙도 그대로이며, 2~3페이즈 누적 패배가 남았다.
3. 이번에는 여러 변경을 함께 적용했다. 효과를 전설 제외·메이저 환산·의무관·연합 중 하나에 단독 귀속할 수 없다.
4. 수호자·의무관·연합을 평가하려면 해당 임계점에 실제 도달하는 전문 정책 또는 고정 전투 상태 비교가 필요하다. 이를 이번 자유 운영 성적과 혼동하지 않는다.
