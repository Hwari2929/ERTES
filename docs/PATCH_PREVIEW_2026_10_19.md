# 2026-10-19 최초 밸런스 시험판 — Claude 인계 메모

> 아래는 PR 첫 커밋의 사양이다. 후속 조정과 500판 짝 비교는 [BALANCE_DURABILITY_500.md](BALANCE_DURABILITY_500.md)를 따른다. 최신 버전은 역경 전설을 제외하고 내구도·시너지 수치를 추가 조정했다.

이 PR은 사용자에게 전달한 단일 HTML 시험판의 소스 변경을 검토·재현하기 위한 초안이다. 기본 브랜치에는 아직 반영하지 않는다. 봇 성적을 재측정하거나 새 밸런스가 검증됐다는 의미는 아니다.

기준 커밋: `f849c818ac2ce1038a735e5e0a9804bd7d99f4b8`.

## 요청과 구현

### 1. 1페이즈 보급 2회

- 기존 실험 설정 `CFG.supply.p1`을 켰다.
- 1페이즈 맨 앞에 보급 노드 1개를 추가하고 첫 역경을 보급으로 바꾼다.
- 1페이즈는 13노드이며, 남은 역경 1회와 보스는 유지한다.
- `CFG.supply.front`는 꺼져 있다. 2페이즈 이후 시작 보급은 추가하지 않는다.
- 기존 항로 보급 생성·뒤집기 로직을 사용한다. 튜토리얼의 별도 항로는 바꾸지 않는다.
- 기존 저장의 이미 생성된 항로를 강제로 재작성하지 않는다. 새 런으로 확인한다.

### 2. 재훤

- 절멸 사격의 5연타 및 탄도 연출을 물리에서 전기로 바꿨다. 사격 위력 참조와 처치 시 쿨다운 환급은 유지한다.
- 기본 계수 0.9를 유지하고 아래 공통 전기 배율을 적용한다. 별도로 0.9를 1.25배 하여 중복 적용하지 않는다.
- 일반 공격 치명타가 피해를 주면 전투 스킬 쿨다운 -1.25초. 스킬·지속·추가 피해에는 적용하지 않는다.
- 전투 스킬 사용 후 공격 속도 +25%p, 5초, 최대 2중첩. 기존 스킬 치명타 확률 +15%p는 제거한다.
- 중첩 만료는 각각 관리한다. 2중첩 상태에서 재사용하면 남은 시간이 짧은 중첩을 5초로 갱신한다.
- 기본 공격의 물리 속성은 유지한다.
- 능력 토큰 설명과 짧은 소개도 함께 수정했다.

### 3. 포티니 양 (사용자 입력의 '포니티')

- 관광 명소 소개의 주 대상에게 도발 계수 +2.5를 적용한다.
- 기존 범위 받는 피해 증가 +15%의 지속을 4초에서 5초로 바꿨다. 기존 관련 증강의 수치 변경은 유지한다.
- 도발 가산은 상태이상에 저장하고 `provMult`가 읽는다. 중복 시 계속 누적하지 않고 지속 시간을 갱신한다.
- **시험판 가정:** 요청에 도발 가산의 지속 시간이 없으므로 받피증과 같은 5초로 정했다. 도발은 주 대상, 받피증은 기존처럼 범위 안 적에 적용한다.
- 기준 소스에는 요청에서 언급한 '기존 도발 +2.5'가 없어서 이 PR에서 함께 구현했다. 별도 최신 패치에 같은 기능이 있다면 중복 적용하지 않는다.

### 4. 고난 이상 역경 장비

- 실제 고난 프리셋은 위험 7이다. `diff >= 7`의 역경 조우에만 적용한다. 모험(위험 6)에는 적용하지 않는다.
- 각 적은 페이즈·일반/정예 여부에 관계없이 장비 3개를 확정 장착한다.
- **시험판 가정:** 재료(C)·고급(G)·희귀(A)·전설(L)을 슬롯마다 독립적으로 각각 25%로 고르고, 해당 등급 안에서 장비를 무작위로 고른다. 중복 장비는 허용한다.
- 전설 1개를 강제로 끼우지 않는다. 무작위 결과에 따라 전설은 0~3개가 될 수 있다.
- 전설 후보는 기존 적 장비 풀을 재사용한다. 재생 외골격의 전설 버전 제외도 유지한다.
- 개조부품 확률과 보스 노드의 기존 장비 규칙은 바꾸지 않는다. 도전 노드는 내부적으로 역경 조우 생성 경로를 쓰므로 같은 규칙을 적용받는다.
- 기준 소스에는 '고난 역경 전설 확정' 코드가 없고 보스의 95% 전설 규칙만 있다. 요청한 최종 상태인 '전설 확정 없이 무작위 등급 장비 3개'를 구현했다.

### 5. 전기·화학·정신·신성 피해

- 아군·적 공통으로 4속성의 치명타를 차단한다. 기술 치명 허용 특성·인과학파 저이성 효과도 이 차단을 우회하지 않는다.
- 공격 분류는 그대로 둔다. 예를 들어 전기 사격은 사격 위력을 쓰지만 치명타는 발생하지 않는다.
- 공통 피해 입구에서 4속성의 기본 피해에 ×1.25를 적용한다. 기본 공격·스킬·추가 피해·지속 피해를 포함한다.
- 직접 체력 비율 피해를 주는 `rawHit` 경로에도 적용한다. 단, 이미 계산된 결속 공유·자아 분리 피해는 `resolved=true`를 전달해 두 번 곱하지 않는다.
- 물리와 고정 피해의 기존 배율·치명타 판정은 유지한다. 이번 요청의 차단 대상은 위 4속성이다.
- 회복·보호막·공격 속도 등 피해 외 수치는 곱하지 않는다.
- 능력 토큰 렌더러에도 같은 배율을 적용해 표시 계수와 전투 계산을 맞췄다. 모든 원본 계수나 속성 상성 배수를 일괄 수정한 방식이 아니다.

## Claude가 검토할 부분

1. 포티니 도발 지속 5초, 주 대상 적용과 범위 받피증 구분이 최종 의도와 맞는지.
2. 장비 등급별 25%가 의도한 확률인지. 전설을 제거한 것이 아니라 '전설 확정'을 제거한 것이다.
3. 일반 피해뿐 아니라 전장 체력 비율 피해와 자기 피해도 해당 4속성이면 ×1.25가 된다. 이 범위가 최종 의도와 맞는지.
4. 기술 치명 관련 설명·증강의 효용 변화. 비물리 기술에는 더 이상 치명타가 나지 않으며, 이번 PR은 해당 증강 자체를 전면 재설계하지 않았다.
5. 기존 정적 밸런스 보고서와 철수의 실측 프로파일은 새 규칙으로 다시 생성하지 않았다. 과거 수치를 새 패치의 평가로 사용하지 않는다.
6. 새 효과를 적용한 상태의 장기 밸런스·플레이 감각은 별도 평가가 필요하다.

```bash
npx tsc --noEmit -p .
npm run -s check
npx esbuild tests/preview_patch_check.ts --bundle --platform=node --outfile=dist/preview_patch_check.cjs --log-level=error
node dist/preview_patch_check.cjs
npm run -s offline
```

- 빌드·타입·도감 및 기존 `check` 검사 통과.
- 추가 회귀 검사: 2,584개 판정 통과. 고난 이상 270개 역경 조우의 적 2,340기에 장비가 정확히 3개인지 확인했다.
- 아군/적 × 사격/타격/기술에서 4속성 치명타 차단 및 1.25배, 물리 치명타 유지, 지속·추가·직접 피해, 공유 피해 중복 배율 방지를 확인했다.
- 재훤 실제 5연사 속성·일반 공격 치명 쿨감·공속 2중첩 상한과 만료, 포티니 실제 스킬의 도발·받피증과 만료를 확인했다.
- 시작 보급의 카드 뒤집기와 변경 기물의 3개 전장 × 일반/역경/보스 총 18전투 종료·유한 수치를 확인했다. 이 소규모 검사는 승률 측정이 아니다.
- 단독 HTML의 인라인 스크립트 구문과 내장 이미지 443개를 확인했다.
- **브라우저 실기동 검증은 환경 문제로 완료하지 못했다.** 시각적·입력 동작 검증 통과로 간주하지 않는다.

`npm run -s offline`의 산출물은 `dist/ERRANTEs-offline.html`이다. 약 44MiB이며 이미지·코드·스타일을 내장한다. 기존 외부 웹폰트 링크는 유지되어 오프라인에서는 대체 폰트를 사용한다.

PR에는 생성된 HTML/이미지를 추가하지 않았다. 사용자가 받은 파일은 위 소스와 오프라인 빌드에서 생성한 시험판이다.
