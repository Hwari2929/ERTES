# 능력 설명 작문 규칙 (스킬 · 특성 · 궁극기 · 증강 · 비술)

능력 하나에 설명이 두 벌 있다.

| 모드 | 어디 | 무엇을 | 수치 |
|---|---|---|---|
| 기본 (상세 보기 꺼짐) | 능력 표 `brief: { skill, trait }` (`src/data/abil/*.ts` · `abiltext.ts`, 없으면 `src/data/brief.ts` `BRIEF`) · 궁극기 `brief` | 무엇을 하는 능력인지 한 줄로, 그림이 그려지게 | 쓰지 않는다 |
| 상세 (상세 보기 켜짐) | `src/data/abil/*.ts` · `abiltext.ts` 의 `text` · `trait` · `augs`, 궁극기 `text` | 아래 문형으로 빠짐없이 | 계수 + 지금 값 (토큰) |

능력 카드 머리의 칩(사거리 · 범위 · 쿨다운)은 두 모드 모두 그대로 둔다.

## 1. 기본 설명 (한 줄)

- 한 문장, `~합니다`체. 40자 안팎, 길어도 2문장.
- 주어는 생략하고, **누구에게 → 무엇을 → 어떤 결과**의 순서로 쓴다. 예: `가장 다친 아군을 치료하고 해로운 효과를 걷어냅니다.`
- 숫자 · 계수 · 확률 · 지속 시간은 쓰지 않는다. 대신 정도를 말로: `크게`, `여러 번`, `잠시`, `가끔`.
- 고유 이름(스킬 이름 · 장비 이름)은 반복하지 않는다 (카드 머리에 이미 있다). 상태 효과는 `[기절]`처럼 대괄호로 남긴다.
- **연출 · 수사 구절을 쓰지 않는다.** `기억을 지워`, `가능하면 한 발로 끝낸다`, `단분자 와이어로`, `급소가 붉게 보인다` 같은 무기 생김새 · 비유 · 의도 묘사는 지운다. 서사는 도감 설명의 몫. 이 규칙은 상세 문장에도 똑같이 적용된다.

## 2. 상세 설명 (문형)

문장마다 `~합니다`체, 한 줄에 한 문장. 효과가 일어나는 순서대로 쓴다: **대상 → 피해 · 회복 → 부가 효과 → 상태 효과 설명 → 조건부 효과**.

### 2.1 대상 · 피해

| 경우 | 문형 |
|---|---|
| 단일 대상 | `N칸 이내의 적에게 OO 위력의 N% OO 피해를 가합니다.` |
| 다단 | `N칸 이내의 적에게 OO 위력의 N% OO 피해를 N회 가합니다.` |
| 주변 범위 | `N칸 이내의 적을 지정해 대상으로부터 N칸 이내의 적들에게 OO 위력의 N% OO 피해를 가합니다.` |
| 여러 대상 지정 | `N칸 이내의 적을 N회 지정해 각각 OO 위력의 N% OO 피해를 가합니다.` |
| 전체 | `N칸 이내의 적 전체에게 OO 위력의 N% OO 피해를 가합니다.` (거리 무관이면 `적 전체에게`) |
| 직선 관통 | `N칸 이내의 적을 향해 직선 위의 모든 적에게 OO 위력의 N% OO 피해를 가합니다.` |
| 바운스 | `N칸 이내의 적에게 최대 N회 바운스되는 OO 위력의 N% OO 피해를 가합니다.` / `바운스 중 결정타를 가하면 바운스 횟수를 N회 회복합니다.` |
| 자기 주변 | `자신으로부터 N칸 이내의 적들에게 OO 위력의 N% OO 피해를 가합니다.` |

- 대상을 고르는 규칙이 '현재 대상'이 아니면 앞에 붙인다: `체력 비율이 가장 낮은 적에게 순간이동해 …`, `가장 먼 적에게 …`.
- 사거리가 거리 무관이면 `N칸 이내의`를 빼고 `적 전체에게`, `무작위 적에게`처럼 쓴다.
- 치명타 · 관통 같은 이번 피해만의 보정은 피해 문장 바로 뒤 문장으로: `이 공격은 치명타 확률이 N%p 상승 적용됩니다.`
- 혼합 속성: `… 사격 위력의 N% 물리 피해와 사격 위력의 N% 화학 피해를 가합니다.`
- '반드시 치명타' · '빗나가지 않음'도 같은 수치 보정 문장으로 쓴다: `이 공격은 치명타 확률과 명중 확률이 100%p 상승 적용됩니다.` (한쪽만이면 `치명타 확률이 100%p 상승 적용됩니다.`). `반드시 치명타가 되며`, `반드시 적중합니다` 같은 표현은 쓰지 않는다.

### 2.2 회복 · 보호막 · 강화

| 경우 | 문형 |
|---|---|
| 회복 | `N칸 이내의 아군을 지정해 OO 위력의 N%만큼 회복시킵니다.` (여러 번: `N회 지정해 각각 …`) |
| 보호막 | `… OO 위력의 N%만큼 보호막을 부여합니다.` |
| 강화 | `N칸 이내의 아군에게 N초간 공격 속도를 N%p 증가시킵니다.` |
| 자신 | `자신에게 …` |

### 2.3 상태 효과

- **키워드 `[OO]`로 감싸는 것은 이름이 붙은 지속 상태뿐**이다: 기절 · 공포 · 빙결 · 매혹 · 혼란 · 출혈 · 중독 · 연소 · 감전 · 제압 · 상흔 · 괴사처럼 고유 규칙이 있는 것.
- 즉발 효과와 단순한 능력치 증감은 키워드로 포장하지 않고 바로 쓴다.
  - 즉발: `대상의 스킬 쿨다운을 3초 증가시킵니다.`, `대상을 2칸 밀어냅니다.`
  - 능력치 증감: `4초간 대상이 가하는 피해를 20%p 감소시킵니다.`, `4초간 대상이 받는 피해를 15%p 증가시킵니다.`, `5초간 대상의 방어도를 50% 감소시킵니다.` (방어도 감소는 곱연산이라 %)
- 부여: `공격이 적중하면 대상에게 N% 기본 확률로 [OO] 효과를 부여합니다.`
  - 규칙: 공격에 딸린 해로운 상태 효과(스킬 부가 효과 · 기본 공격 특성)는 그 공격이 **적중한 대상에게만** 걸린다 (`Battle.missed`). 그래서 공격에 딸린 효과는 늘 `공격이 적중하면`으로 시작한다. 공격 없이 거는 효과(오라 · 주기 효과 · 지원)는 그대로.
  - 기본 확률 = 효과 적중 · 효과 저항이 보정하는 확률. 보정을 받지 않으면 `고정 확률`.
  - 100% 이면 `반드시 [OO] 효과를 부여합니다.`
- **설명 문장은 직접 쓰지 않고 `[fx]` 토큰으로 부른다.** 부여 문장에서 키워드 자리에 `[fx:키:지속(:추가 인자)]`를 쓰면 그 자리는 `[OO]`로 보이고, 설명 문장은 `STATUS_FX`(src/data/abiltext.ts)에서 만들어 능력 설명 맨 끝에 한 번만 자동으로 붙는다. 지속 · 계수만 능력마다 적는다.
  - 예: `공격이 적중하면 대상에게 [p:0.4] 기본 확률로 [fx:fear:1] 효과를 부여합니다.` → 끝에 `[공포] 효과가 부여된 적은 공격과 스킬 사용이 불가능하며, 1초 지속됩니다.`
  - 지속 피해: `[fx:poison:4:shoot:0.25]` (지속, 위력, 계수) · 중첩형 `[fx:burn:5:strike:0.144:5]` (… 최대 중첩)
  - 설명 문장의 꼴: `[OO] 효과가 부여된 적은 (할 수 없는 행동 / 바뀌는 상태)…며, N초 지속되고, 최대 N회 중첩됩니다.` — `~하지 못하게 합니다`가 아니라 대상이 무엇을 할 수 없는지를 쓴다. 표에 없는 상태는 STATUS_FX 에 먼저 추가한다.
  - 같은 능력 안에서 같은 효과는 한 번만 설명된다 (자동 중복 제거).
- **다른 능력이 정한 효과를 그대로 다시 거는 경우** (특성 · 지속 능력이 거는 [중독]을 스킬이 같은 크기로 더 거는 등) 설명을 되풀이하지 않고 출처를 가리킨다: `이어서 대상에게 반드시 "지속 능력 - 대사"의 [g:poison] 효과를 2중첩 부여합니다.` (`[g:]` 로, `[fx:]` 아님)

### 2.4 조건 · 반복

- 조건부: `OO하면 ~합니다.` (처치, 적중, 피격, 체력 N% 이하 …)
- 주기: `N초마다 ~합니다.` / 횟수: `N번째 기본 공격마다 ~합니다.`
- 제한: `전투당 1회.` 같은 짧은 꼬리 문장은 허용.

### 2.5 증강 · 특성

- 증강은 바뀌는 것만 쓴다. 기존 수치가 오르면 `OO의 피해가 OO 위력의 N%만큼 증가합니다.`, 새 효과면 2.1~2.4 문형 그대로.
- 능력치 증강은 `전투력 +6, 기동력 +9.`처럼 이름 + 값 나열을 허용한다.
- 특성(지속 효과)은 주어 없이 조건부 문형: `기본 공격이 적중하면 …`, `전투가 시작되면 …`.

## 3. 표기

- 숫자는 아라비아 숫자. 시간 `초`, 거리 `칸`.
- **`%` 와 `%p`**: 다른 효과와 **더해지는** 가산 효과는 모두 `%p` (가하는 피해 증가 · 받는 피해 증가 · 피해량 경감 · 확률 · 공격 속도 · 회피 · 최대 체력 % 증가 등 — 엔진의 inc · vuln · red · 능력치 가산 · pct). **곱해지는** 효과(증폭 amp, 방어도 ×, 계수 ×)와 계수 자체(`위력의 N%`)는 `%`.
- **증감 동사는 `증가` · `감소`로 통일한다.** 타동: `증가시킵니다` · `감소시킵니다`, 자동: `증가합니다` · `감소합니다`. `늘립니다 · 줄입니다 · 높입니다 · 낮춥니다 · 늘어납니다 · 줄어듭니다 · 떨어뜨립니다 · 올립니다` 는 쓰지 않는다.
  - 예: `공격이 적중하면 4초간 대상이 받는 피해를 15%p 증가시킵니다.`, `공격이 적중하면 3초간 대상의 명중 확률을 30%p 감소시킵니다.`
- 위력 이름: 사격 위력 · 타격 위력 · 기술 위력 · 전술 위력. 피해 속성: 물리 · 화학 · 전기 · 정신 · 신성 · 고정.
- 상태 효과 · 용어는 `[OO]` (용어 설명 칩으로 이어진다).

## 4. 토큰 (상세 문장 안)

| 토큰 | 보이는 모양 |
|---|---|
| `[pw:shoot:1.8]` | `사격 위력의 180%(324)` — 괄호 = 지금 값 (기물이 없으면 생략) |
| `[el:phys]` | `물리` (속성 색 · 아이콘) |
| `[t:2]` | `2칸` |
| `[s:4]` | `4초` |
| `[p:0.3]` | `30%` |
| `[pp:0.15]` | `+15%p` |
| `[pv:0.15]` | `15%p` — 증감 동사(상승 · 증가 · 감소)와 함께 쓸 때 |
| `[g:stun]` | `[기절]` (용어 칩) |
| `[fx:stun:1.5]` | `[기절]` + 능력 설명 끝에 상태 효과 설명 문장 자동 추가 (2.3) |
| `[pw:tac:2]` · `[pw:main:1]` · `[pw:prime:1]` | 전술 위력 · 사이오닉 주요 위력 · 성유물 주력 위력 |

예: `[t:4] 이내의 적에게 [pw:tech:1.6] [el:psy] 피해를 가합니다.`
