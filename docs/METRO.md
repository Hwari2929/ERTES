# 메트로 인피니티 패스 테마 명세

인게임 UI 를 성간 열차의 표 · 역 · 승강장으로 그리는 테마 — **구조는 항상 브루탈, 반짝임은 순간에만.**

[docs/UI.md](UI.md) 의 공통 원칙이 먼저이고, 이 문서는 메트로 테마에만 쓴다. 메트로 UI 를 고치기 전에 UI.md 와 함께 읽는다. 본문의 '13번' · '35번' 같은 번호는 UI.md 1절 원칙 번호이고, '2절' · '5절' 은 이 문서의 절이다. (2026-11-07 UI.md 2절 기준 사례 표의 메트로 줄을 옮겨 부품 · 화면별로 나눴다.)

## 1. 개요 · 범위

- 파일: ui/themefx.ts · css/01-themes.css 토큰 · css/26-metro.css. 부품 기준 = 디자인 시스템 'ADMIT ONE'.
- **인게임에만 · 재료는 `--mt-*` 토큰만** (바 · 계약 · 타이틀 · 사건 장면 제외 `:not(:is(.bar, .ct, .title-screen, .adv) *)`).
- 타이틀(제외 구역)은 색 토큰만 메트로를 따른다 — 구조선 · 글자 크기 · 알약 둥글기는 제외 구역 값 그대로 (2026-11-07 사용자 결정, 피드백 보고서 D3. 이전: 갤럭시 색 `--gx-*`).
- **METRO 는 에란테스 것이 아니다** (2026-11-06 사용자 결정): 성간 항로 조합이 운영하는 민간 · 상업 여객 성간 열차 체계와 그 하위 메트로 패트롤을 통틀어 부르는 이름 — 표 · 객차 · 카드 뒷면 같은 장식 문구에 ERRANTES · 에란테스 · 바 같은 에란테스 용어를 넣지 않는다 (METRO · GLOBAL PASS · SUPPLY · BOARDING PASS 처럼 노선 쪽 말만).
- 함께 볼 [UI.md](UI.md) (원칙 안에 메트로 몫을 적은 곳): 10번 (창밖 별빛 · 굵기 강조 예외) · 13번 (증강 등급색 `--gc` · `--tc`) · 35번 (누를 것의 그림자 · 주 동작) · 36번 (업적 도장 점선 고리) · 37번 (표가 절취선에서 찢어진 뒤 실행) · 39번 (다시 뽑기 = 표 머리 바코드 바로 왼쪽), UI.md 2절 기준 사례의 상인 상점 · 순례 성소 줄, UI.md 4절 점검 (절취선 `--mt-perf`).

## 2. 원칙

- **구조는 항상 브루탈, 반짝임은 순간에만** (2026-11-07 사용자 결정 — 피드백 보고서 1단계, 디자인 시스템 ADMIT ONE 의 스타일 혼합 규칙): 평소 화면의 구조(윤곽 · 면 · 오프셋 그림자 · 판과 누를 것의 구분)는 늘 네오 브루탈로 세운다. 평소 부품 = 디자인 시스템 둥글기 · 1.5px 윤곽 · shadow-sm, 큰 전환 · 경고 판 = 한 단계 더 세게(각진 모서리 · 굵은 윤곽 3px · 흐림 없는 큰 그림자 12~14px · 대문자 모노 표기). 반짝임(크롬 · 글린트 · 홀로)은 전환 · 보상 · 등급 상승의 순간에만 쓴다.
- 다만 담는 판은 각지게(판 4px `--mt-r-panel` · 창 6px `--mt-r-win` — 누를 것 · 표는 각자 둥글기), 윤곽 대비 3:1(`--mt-edge`).
- 굵기 · 종이 면으로 하는 강조의 메트로 예외는 [UI.md](UI.md) 10번 끝에 있다 (2026-11-07 사용자 결정).
- 딱딱한 그림자는 모두 오른쪽 아래(빛 = 왼쪽 위).
- **패널 장식은 하나** (도장 · 망점 · 바코드를 한 패널에 겹쳐 쌓지 않는다).
- 쿠폰 모양(홈 · 뜯는 칸)은 받는 것(결과 보상)에만 쓰고 단추에는 쓰지 않는다 (노드 화면 상품은 2026-11-06 부터 사는 미니 카드).
- 선: 절취선(뜯는 곳 · 스텁 경계)만 `--mt-perf` 점선 하나, 칸 · 줄 구분은 실선.
- 그림은 큰 한 색 면 위주, 글로우 없음.
- 형태 · 위계 값(구조선 굵기 · 색, 둥글기, 누를 것 그림자 색, 표 머리 바탕, 값 숫자 글꼴, 글자 크기)은 구조 토큰으로 바꾼다 — 선택자마다 덮어쓰지 않는다 (14절).

## 3. 색 · 망점

같은 색을 다른 뜻에 쓰지 않는다 (13번):

| 뜻 | 색 |
|---|---|
| 강조(선택 · 다음 행동) | 복숭아 `#ff9b6a` (2026-11-05 채도 올림) |
| 신호(보스 · 역경 · 패배) | 위험 빨강 `--c-bad` |
| 지속 피해 | 라임 `#cfe35a` |
| 가리킴 | 밝은 회색 `--mt-hover` (보라는 합성 재료 등급색과 겹친다) |

- **기록 (2026-11-06 사용자 결정, 13번 예외)**: 크레딧 `--c-credit` · 장식 복숭아 `--mt-c`(노선 띠 · 상점 전환 패널)는 강조색 복숭아와 같은 값을 쓴다 — 13번 점검에서 겹침으로 지적됐으나 테마 정체성 쪽을 택함.
- 망점(하프톤, 사용자 요청 2026-11-05 — 26번 명암 금지의 예외): 고정 크기 SVG 토큰 `--mt-dot-*` 를 늘이지 않고 모서리에 찍는다 (탑승권 판 그림자 = 우하단 끝으로 옅게, 결과 승패 띠 = 망점 없음 (장식은 VALID · VOID 도장 하나 — 2026-11-06), 보급 앞면 = 일련번호 줄 오른쪽에서 우하단으로 짙게 — 넓은 토큰을 뒤집어 글자와 겹치지 않는 자리에만).
- 다른 절의 토큰: 둥글기 · 윤곽 `--mt-r-panel` · `--mt-r-win` · `--mt-edge` · 절취선 `--mt-perf` = 2절, 로고 글꼴 `--f-logo` · `--f-sign` = 4절, 별 하늘 `--mt-sky` = 5절, 바닥 `--mt-floor` · 그림자 `--mt-sh` = 6절, 종이 머리 `--mt-head` · 정차 번호 `--mt-no` = 7절, 등급색 `--g-C` · `--g-A` · `--g-L` = 9절, 타이틀 갤럭시 색 `--gx-*` = 1절.

## 4. 글꼴 · 머리표 · 로고

- **모노 글꼴 = 영문 · 숫자 전용** (2026-11-06, 디자인 시스템 ADMIT ONE 머리표 규칙):
    - 머리표 · 장식 문구는 영문만 (영문과 한글을 한 머리표에 섞지 않는다 — NOTICE · MISSION COMPLETE · GATE 01)
    - 한글 라벨(표 머리 · 구획 제목 · 수치 이름 · 칸 이름 · 머리표 자리의 한글)은 본문 글꼴 굵게 13px 이상(`--fs-sm`, 2026-11-07 한글 최소 읽기 크기 — 이전 11~12px) · 자간 .02em
    - 숫자 + 단위 값(3명 · 6.6초 · 0회)은 모노 그대로.
- **상단 바 로고 = INFINITE METRO Express** (2026-11-07 사용자 결정 로고 시안 1: INFINITE = 모노 민트 넓은 자간 / METRO = Archivo Black 종이색 / Express = 필기체 복숭아, METRO 오른쪽 아래에 비스듬히 겹침 — 로고 글꼴은 index.html 에서 그 글자만 받는다 `--f-logo` · `--f-sign`, 갤럭시는 ERRANTEs 그대로).
- **상단 바 = 종이 행선판** (2026-11-07 사용자 결정 2단계 B2-1): 종이 바탕 · 아래 잉크 2px 선 (바 아래 민트 · 보라 노선 띠는 뺐다), 로고 = METRO 잉크 · INFINITE 짙은 민트 · Express 짙은 복숭아, 칩 = 잉크 윤곽 (체력 · 크레딧 숫자는 제 색을 잉크 쪽으로), 메뉴 단추 · 휴대폰 시너지 마름모 = 잉크 판.
- **머리표 어휘 = 성간 여행** (2026-11-07 사용자 결정 C1 — 피드백 보고서 3단계: 지하철로 읽히는 말을 항공 · 우주 여행 말로):
    - 바꾼 것: 다음 칸 NEXT PORT (← NEXT STOP) · 상점 머리 MARKET · DUTY FREE (← MARKET · NEXT STATION) · 상점 전환 표 NEXT PORT (← NEXT STATION) · 분기점 카드 GATE 01 (← PLATFORM 01) · 특권 막 NOW BOARDING · GATE ∞ (← PLATFORM ∞) · 페이즈 배너 COURSE CHANGE (← LINE CHANGE) · 런 출발 표 PHASE n · ROUTE ∞ (← LINE ∞) · 역경 배너 TURBULENCE (← RAPID) · 보스 배너 · 급행 차체 띠 EXPRESS · NON-STOP (← NO STOP).
    - 그대로: NOW BOARDING · DEPARTURE · BOARDING PASS · ADMIT ONE · GATE ∞ · GATE OPEN · TRANSFER · JUNCTION · TERMINAL · METRO (항공 · 우주 여행에도 쓰는 말).
- **가상 브랜드 로고는 보류** (2026-11-07 사용자 결정 C7 — 벡터 로고 시안 6개는 디자인이 쉽지 않아, 나중에 그림 생성(NovelAI)으로 뽑는다 · 요청할 때만): 성간 항로 조합 · 주식회사 페트라 · 호이슌 홀딩스. 함께 미정 = METRO ∞ PASS 를 조합 승객용 패스 앱으로 설정에 적을지(D2 — 설정상 조합이 고대 열차 플랫폼 '메트로'를 복구 · 운영한다), 조합 영문 이름(제안 INTERSTELLAR ROUTE UNION · IRU), 호이슌 영문 표기(설정 Hoishun · 투자 데스크 머리표 HOISUN).

## 5. 별 하늘 · 창밖

- **별을 달리는 노선** (2026-11-06 피드백 '심야 지하철에 가깝다'): 잉크 면에는 별 하늘 토큰 `--mt-sky`(무작위로 흩뿌린 별 타일 두 장 600×400 · 470×330 — 크기 · 색 · 밝기가 제각각, 바둑판처럼 줄지어 보이지 않게, scripts/mt_sky.py)
    - 보스 급행 차창 너머 = 흐르는 별 하늘 + 아래 붉은 경보 빛 (보스 실루엣 = 빨간 윤곽)
    - 런 출발 게이트 잉크 막대 = 막대를 건너 이어지는 밤하늘
    - 상점 · 전투 진입 잉크 패널 = 모눈 위 별 하늘
    - 상점 전환 큰 망점 → 별자리
    - 전환의 잉크 판 · 게이트 막대의 별은 판이 멈춰 있는 동안에도 천천히 흐른다 (14초에 타일 한 바퀴, 움직임 줄이기 = 멈춤)
    - 창밖 별빛 층은 전투 중(일시 정지 포함)에도 어둡게 · 4분의 1 빠르기로 흐른다 (탑승권 스텁은 METRO 그대로).
- **창밖 천체 · 풍경 층은 두지 않는다** (2026-11-07 사용자 결정 C4 — 행성 지평선 · 지나가는 천체(SVG) · 전장 그림 풍경 띠 시안 모두 반려): 항로도(인쇄 노선표) · 노드 표(지금 칸 종이 표)가 밝아져서 바탕층 장식은 묻힌다. 다른 것을 밝게 가져가지 않는 한 바탕에 그림을 더하지 않는다.

## 6. 판 · 단추 (35번 구분)

- 화면에 붙는 띠(아래 동작 줄 · 편성 머리)는 같은 고정 바닥 `--mt-floor`.
- 35번 구분:
    - 창 · 노드 표 · 열린 보급 카드 = 평평한 판(2px 윤곽 `--mt-stroke` + 위 노선 띠 — 2026-11-07 B6 이전 1.5px)
    - 단추 = 평평한 단추(둥글기 6 · 불투명 바탕 — 유령 단추도 뒤가 비치지 않게)
    - 주 동작 = 복숭아 면 + 잉크 테두리(2px) + 잉크 글자 + 종이 그림자 + 좌상단으로 짙어지는 흰 망점, 망점은 글자 아래 (2026-11-07 사용자 결정 2단계 B3 · 테두리 시안 1 — 테두리가 없으면 흰색과 피치가 섞이지 않는다 — 이전 2026-11-06: 일반 단추 + 복숭아 그림자만). 종이 면 위(표 머리 · 지금 칸 표)에서는 그림자 = 잉크. 카드 안 '선택' 같은 보조 primary(.pc-pick)와 비활성은 일반 단추. 쿠폰형(티켓 홈)은 css 주석으로 보존 — 진입 · 닫기 · ✓ 같은 단추는 쿠폰일 이유가 없다
    - 모든 단추 · 고르는 카드 = 선명한 오른쪽 아래 그림자(색 = 잿빛 `--mt-sh` 하나 — 단추 · 탑승권 모두, 2026-11-06 사용자 결정: 종이색은 과하고 보라는 구별이 안 된다 / 켜짐 · 고른 것 = 선택색, 전역 증강 = 등급색, 비활성 · 유령 = 없음), 가리키면 밝은 회색 윤곽.

## 7. 머리 · 창

- 판 머리는 종이 머리(`--mt-head` 종이 → 보라 — 이번 전투 · 알림 창).
- 노드 화면(속보 · 투자 · 합성 공방 · 암시장 · 상인 상점 · 순례)과 고르기 창(전역 증강 · 보급 · 전리품 · 감시 포탑 장비 · 공명 증강 · 영입 · 지정 소집 · 분기점 · 전환 · 축복)의 머리 = 표 머리 `.mt-hd` (2026-11-06 사용자 결정, 일상 브루탈 시안 3). 2026-11-06 사용자 결정 검토 A:
    - 바탕 = 종이 → 노드색 그라디언트 (2026-11-07 사용자 결정 2단계 B1-2, 이번 전투 · 알림의 종이 머리와 같은 문법 — 이전: 잉크 띠). 글자 · 바코드(`--mt-barcode-ink`) · 정차 번호 = 잉크, 머리표 = 노드색을 잉크 쪽으로 누른 색, 칩 = 잉크 윤곽(주요 적 칩은 제 색을 잉크 쪽으로), 머리 도구 단추는 잉크 단추 그대로
    - 노드색 굵은 아래 선 · 왼쪽 머리표(영문 모노 = h1 data-k, 노드색) · 제목 · 칩 · 오른쪽 끝 = 바코드 위 + 정차 번호 `NO. 07` 아래 (지금 칸 번호 = 상단 바 칸 번호, main.ts `--mt-no`)
    - 한 줄 머리(영입 · 상인 상점 · 순례)는 바코드와 번호를 나란히, 1000px 이하는 번호만.
    - 머리 도구(새로고침 · 마치기)는 바코드 바로 왼쪽, 39번. 새로고침 = ↻ 아이콘 단추 40px(터치 44px · 2026-11-07 사용자 결정 C6-1): 큰 머리는 바코드와 가운데 맞춤, 한 줄 머리는 도구 줄 맨 앞, 머리 띠 없는 창(특권 · 절망)은 오른쪽 위. 남은 수가 2 이상이면 아래 오른쪽 복숭아 작은 수, 다 쓰면 비활성. 상점은 아이콘 + 값(무료 · 크레딧).
- 알림 · 의뢰 성공 = 확인 창(디자인 시스템 Modal: 종이 → 보라 머리 띠 · 머리표 NOTICE / MISSION COMPLETE · 경계 양옆 홈, 의뢰 성공 = VALID 도장).
- 기물 전체 상세 안쪽 = 구획 제목 민트 네모 · 그림 칸 AGENT 머리표 + 아래 보라 그라디언트.
