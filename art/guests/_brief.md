# 바 낯선 손님 명부 — 작성 지침 (에이전트 공용)

> 보고는 한국어로. 이 단계는 **명부(인물 설정 + 그림 태그)만** 쓴다. 대사는 다음 단계. NovelAI 생성 · 커밋은 하지 않는다. 지정된 JSON 파일 하나만 만든다.

## 배경
- 게임 ERRANTEs. 에란테스 바 = 용병단 에란테스의 본부이자 실제 바. **알렉산드리아 궤도 정거장**(중립 구역)에 있다. 알렉산드리아는 헬레니우스 동맹 영토의 항성 없는 부유 행성이고 범은하 공동체 의회가 열리는 곳 (`lore/지역/동맹/알렉산드리아.md`). 바의 낮 · 밤은 정거장 인공 일광 주기.
- 바텐더: 낮에는 고대 안드로이드 **에이든**, 밤에는 지휘관 **레이첼**이 직접 잔을 만든다. 손님은 레이첼에게 술을 주문한다.
- 낯선 손님은 처음 몇 번은 이름 없는 '낯선 손님'으로 오다가, 어느 방문에 레이첼에게 말을 걸어 대화를 나누고 이름을 밝힌다. 그 뒤로는 이름으로 불리는 단골이 된다. 한 명당 나중에 대사 약 50줄(주문 · 반응 · 작별 · 혼잣말 · 이름 밝히는 대화 · 화제 2편)이 붙는다 — 그래서 **말투와 성격이 서로 뚜렷이 달라야** 한다.

## 먼저 읽을 것
- `CLAUDE.md` (사건 연출 · 숫자는 아라비아 숫자)
- `lore/README.md`, 맡은 세력의 `lore/세력/*.md` · `lore/_틀/*.md` · `lore/지역/<연합|제국|동맹>/*.md` (필요한 부분)
- `docs/VOICES.md` (어체 표기 방식 · 금지 사항), `docs/BAR_OPS.md` 5절 (낯선 손님 유형 · 주문 방식)
- `src/data/bar/drinks.ts` (레시피 · `OrderStyle`), `art/guests/_names.txt` (겹치면 안 되는 이름 · 레시피 id 목록)
- `art/prompts.json` 의 태그 쓰는 법 (예: `yelena`, 환수 단원 `orca` 등 `grep -n '환수\|animal ears\|tail' art/prompts.json` 으로 찾아 참고)

## 지킬 것
- 세계관과 어긋나지 않게: 출신지 · 소속 단체는 lore 에 있는 것만. 새로 지어내는 것은 **개인 설정(직업 · 사연 · 버릇)** 수준까지. 큰 사건 · 새 세력 · 새 행성은 만들지 않는다.
- 넣지 않는 것: **시리우스 성도회** 소속, **유닉스 코퍼레이션** 로봇(자아가 없어 주문하지 않는다), 군체.
- 모두 성인 (외형도 성인). 이름은 고유하고 `_names.txt` 의 이름 · 다른 손님과 겹치지 않게, 세력의 이름 짓는 결을 따른다.
- 20명 안에서 성별 · 나이(20대~노년) · 직업 · 성격 · 말투 · 체형 · 색 배치가 고르게 다르게. 같은 직업 · 같은 성격 반복 금지.
- 레이첼(**10대 후반~20대 초 외형**의 젊은 여성 지휘관, 바 주인 — `docs/VOICES.md` 레이첼 항목)에게 쓰는 어체를 정한다: 해요체 · 합쇼체 · 반말 · 하게체 등 섞어서. 첫 만남 손님이 대뜸 반말하면 성격 이유가 있어야 한다.
- `when`: 주로 오는 시간. 낮 손님이 밤 손님보다 많게 (20명 중 낮 9 · 밤 6 · 아무 때 5 정도). 관광객 · 회사원은 낮, 용병 · 망령 · 야간 근무자는 밤.
- `style`(주문 방식) 섞기: `vague`(느낌으로 — 관광객) · `name`(메뉴 이름으로 — 회사원) · `usual`(늘 마시던 거 — 동네 단골) · `photo`(남이 마시던 잔을 찍어 와서 — 신참 용병) — 20명 중 각 3명 이상.
- `tip`: 0 짠돌이 · 1 보통 · 2 후함 (관광객은 후한 편).
- `menu`: 단골 메뉴 = `_names.txt` 의 레시피 id 중 하나 (성격 · 취향에 맞게, 고르게).
- 망령: 사이오닉 응집체 (`lore/세력/헬레니우스 동맹.md` 5절). 대화가 되는 '마모 초기' 망령만. 마시는 시늉 · 향만 즐기는 등 설정을 붙인다.
- 기계: 자아가 있는 안드로이드 · 사이보그 · 오토마타 (유닉스 로봇 아님). 사람 모양으로 바에 앉을 수 있어야 한다.
- 환수: 동물 귀 · 꼬리부터 동물 얼굴에 가까운 수인까지 (lore 의 환수 묘사를 따른다).

## 출력: `art/guests/<group>.json`
배열. 각 항목:

```json
{
  "id": "u_halden",            // 접두(맡은 세력) + 영문 소문자 · 숫자 · _ (그림 id 는 gs_<id>)
  "name": "할덴 모로",          // 한국어 표기 (이름 밝힌 뒤 이름표)
  "group": "union",
  "org": "연합 해군 보급창 · 하사",   // 소속 · 직업 한 줄
  "from": "카운티폴",             // 출신 (lore/지역 · 세력 문서에 있는 곳)
  "race": "human",              // human | beast | machine | wraith | other
  "kind": "인간",                // 세부 ('여우 환수' · '구형 가정용 안드로이드' · '마모 초기 망령' …)
  "sex": "m",                   // f | m | x
  "age": "41",                  // 숫자 또는 '불명' · '외형 20대'
  "look": "짧게 친 회색 머리, 소매 걷은 정비복, 왼손 의수",   // 외형 한 줄
  "persona": "…",               // 성격 2~3문장
  "voice": "해요체 · 말끝을 늘인다 · 숫자를 꼭 세어 말한다",   // 레이첼에게 쓰는 어체 + 말버릇
  "why": "…",                   // 이 정거장 바에 오는 이유
  "when": "day",                // day | night | any
  "menu": "dtonic",             // 레시피 id
  "style": "name",              // vague | name | usual | photo
  "tip": 1,
  "hook": "…",                  // 이름을 밝히는 대화의 화제 한 줄
  "subject": "1boy",            // 1girl | 1boy | 1other
  "tags": "…, full body, standing, looking at viewer"
}
```

### tags (NovelAI 영어 태그)
- `art/prompts.json` 과 같은 결: 나이대 · 체형 · 머리(색 · 길이 · 모양) · 눈 · 표정 · 옷(위아래 · 신발) · 소지품 · 종족 특징을 쉼표로. 25~45개. 끝은 `full body, standing, looking at viewer`.
- 화풍 · 작가 · 품질 · 배경 태그는 넣지 않는다 (공용 앞 태그가 붙는다). 글자 · 로고 · 여러 모습(multiple views) 금지.
- 망령: `ghost, translucent body, faint glow, faded colors` 같은 반투명 표현 + 생전 옷차림. 기계: `android, mechanical joints, visible seams, robot ears` 등. 환수: `fox ears, fox tail` / 더 짐승에 가까우면 `furry, animal face` 등.
- 20명의 실루엣 · 주색이 서로 겹치지 않게.
