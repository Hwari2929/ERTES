# 바 낯선 손님 대사 — 작성 지침 (에이전트 공용)

> 보고는 한국어로. 맡은 명부(`art/guests/<group>.json`)의 손님마다 대사 약 50줄을 `src/data/bar/guestlines/<group>.ts` 에 쓴다. 다른 파일은 고치지 않고, 커밋 · NovelAI 생성은 하지 않는다.

## 먼저 읽을 것
- `CLAUDE.md` 사건 연출 절 (대사는 소리 내어 읽어 자연스러운 구어체 · 전보체 금지 · **숫자는 아라비아 숫자** · 지휘관 = 레이첼)
- `docs/SCENES.md` '한국어 대사 작성 원칙' · 3차 지침, `docs/VOICES.md` (레이첼 항목: 10대 후반~20대 초 외형, 반말 기본 · 처음 보는 어른에겐 건성으로 해요체 · 단답)
- `art/guests/_brief.md` (명부 지침) · 맡은 명부 JSON 전체 (persona · voice · why · hook 이 대사의 근거)
- 예시: `src/data/bar/firstmeet_a.ts` (첫 만남 대본 형식), `src/data/bar/orderlines_a.ts` (주문 · 반응 · 거두기 대사 결), `src/data/bar/talk.ts` (말 걸기 화제)
- 세계관: 그 손님 출신 · 소속의 `lore/` 문서

## 상황
- 에란테스 바 = 알렉산드리아 궤도 정거장(중립 구역)의 용병단 본부 겸 실제 바. 낮(07~19시)에는 에이든(고대 안드로이드)이 바텐더, 밤에는 레이첼이 혼자 카운터를 본다.
- 손님은 처음 1~5번 방문까지 이름 없는 '낯선 손님'이다. 그동안 나오는 대사(enter · order · 반응 · drop · leave · mono 앞 3줄)는 **이름 · 직업 · 사연을 직접 밝히지 않는다** (말투와 버릇으로만 성격이 보이게, 넌지시 흘리는 정도는 괜찮다).
- 어느 방문에 손님 머리 위에 표시가 뜨며 레이첼에게 먼저 한마디 건다 (call). 레이첼이 누르면 대화창(meet)이 열리고, 그 끝에 이름을 밝힌다. 그 뒤로는 이름으로 불리는 단골 — 말 걸기 화제 2편(topics)과 mono 뒤 3줄이 열린다.

## 형식 (`src/data/bar/guestlines.ts` 의 `GuestLines`)
```ts
import type { GuestLines } from '../guestlines';
export const GUEST_LINES_UNION: Record<string, GuestLines> = {
  u_halden: {
    enter: ['…', '…'],                 // 2 — 들어와 앉으며 혼잣말 (무대 말풍선)
    call: ['…', '…'],                  // 2 — 이름 밝히기 전, 레이첼에게 먼저 거는 짧은 한마디 (표시와 함께 뜬다)
    vague: ['{feel} …', '…{feel}…'],   // 2 — 느낌으로 주문 ({feel} = '달고 청량하게, 시트러스 향 나게' 같은 부사형 문구)
    photo: ['…', '…'],                 // 2 — 사진(남이 마시던 잔)을 보여 주며 주문
    name: ['{menu} …', '…{menu}…'],    // 2 — 메뉴 이름으로 ({menu} 뒤 조사는 fillText 가 맞춘다: '{menu}으로' 처럼 받침 있는 쪽으로 쓴다)
    usual: ['…', '…'],                 // 2 — '늘 마시던 거'
    hint: '…{menu}…',                  // 1 — 밤에 늘 마시던 걸 시켰는데 레이첼이 모를 때 흘리는 귀띔
    like: ['…', '…'], ok: ['…', '…'], bad: ['…', '…'],   // 각 2 — 한 모금 뒤 반응 (좋아함 · 그럭저럭 · 별로)
    drop: ['…', '…'],                  // 2 — 주문을 못 받은 채 일어나며 (원망하지 않는 투, '다음에')
    leave: ['…', '…', '…'],            // 3 — 작별 인사
    mono: ['…', '…', '…', '…', '…', '…'],  // 6 — 혼잣말 (앞 3줄 = 이름 전에도, 뒤 3줄 = 이름 밝힌 뒤 — 사연이 조금 더 드러남)
    meet: ['* …', '…', '레이첼: …', …],    // 10~16줄 — 이름 밝히는 대화 (hook 화제). 끝 무렵에 손님이 이름을 말한다
    topics: [                          // 2편 — 이름 밝힌 뒤 말 걸기 화제, 각 5~8줄
      { label: '…', lines: ['…', '레이첼: …', …] },
      { label: '…', lines: [ … ] },
    ],
  },
};
```
- 줄 형식: 손님 대사는 이름표 없이 그대로, 레이첼 대사는 `레이첼: …`, 서술은 `* …` (meet · topics 에서만, 짧게). 에이든이 끼면 `에이든: …` (낮 장면일 때만).
- meet 는 첫 줄을 `* ` 서술로 시작해 자리를 잡는다 (예: '* 카운터 끝자리. 그 손님이 빈 잔을 밀어 놓으며 레이첼을 부른다.'). 이름을 말하는 줄은 자연스럽게 (명함 읽듯 하지 않게).
- topics 의 label 은 메뉴에 뜨는 짧은 화제 이름 (예: '리빈산 페르마', '보안관 배지').
- 한 줄은 말풍선에 들어가게 1~2문장 (대략 50자 안쪽). meet · topics 줄도 길게 늘이지 않는다.
- 손님 사이에 같은 문장 · 같은 농담을 되풀이하지 않는다. 주문 · 반응 대사도 그 손님의 성격 · 말투 · 직업이 묻어나게.
- 레이첼은 짧게 받아치는 반말이 기본 (처음 보는 어른에겐 건성으로 해요체). 레이첼 대사를 길게 쓰지 않는다.
- 망령 · 기계 손님은 마시는 방식(향만 맡는다 · 마시는 시늉 · 연료 대신 등) 설정을 대사에 살린다.

## 확인 · 보고
- `npx tsc --noEmit -p .` 통과 (`src/data/bar/guestlines.ts` 의 `GuestLines` 형에 맞게).
- 손님마다 칸 수 (enter 2 · call 2 · 주문 4방식 각 2 · hint 1 · 반응 각 2 · drop 2 · leave 3 · mono 6 · meet 10~16 · topics 2편).
- 보고(한국어): 손님별 meet 의 이름 밝히는 줄 한 줄씩, 세계관에서 확신이 없던 점.
