# 바 낯선 손님 × 에이든 만담 — 작성 지침 (에이전트 공용)

> 보고는 한국어로. 맡은 손님(`art/guests/_aiden_pick.json` 의 지정 세력 몫)마다 에이든과 주고받는 짧은 만담 3편을 `src/data/bar/guestaiden/<a|b|c>.ts` 에 쓴다. 다른 파일은 고치지 않고, 커밋 · NovelAI 생성은 하지 않는다.

## 먼저 읽을 것
- `CLAUDE.md` 사건 연출 절 (구어체 · 전보체 금지 · **숫자는 아라비아 숫자** · 지휘관 = 레이첼)
- `docs/SCENES.md` '한국어 대사 작성 원칙', `docs/BANTER.md` (만담 모양 8종 — 펀치 · 받아치기 · 투덜 · 3인 · 여운 · 확전 · 끊김 · 회수, 한 손님의 3편은 서로 다른 모양으로)
- `docs/VOICES.md` 의 **에이든** 항목 (합쇼 · 해요체, 능글맞게 놀림, 손님을 이름 대신 주문으로 부름 — "핫초코 곱빼기 손님", 메뉴판에 없는 메뉴, 현대 술은 열등하다는 고집. 금지: 구인류 · 대승천 회고, 인류에 대한 진지한 평가, 감상적 고백, 이름을 제대로 부르기)
- 맡은 손님의 명부(`art/guests/<세력>.json`: persona · voice · why · menu · when)와 이미 쓴 대사(`src/data/bar/guestlines/<세력>.ts`: 말투 · 버릇 · meet · topics) — 그 손님의 말투를 그대로 이어 간다
- 예시: `src/data/bar/talk.ts` 의 `BAR_IDLE` (에이든과 손님 대화)

## 상황
- 낮(07~19시) 에란테스 바, 에이든이 카운터 안에 있고 그 손님이 카운터에 앉아 있다. 무대 말풍선으로 재생된다 (위쪽 상황 줄 없음 — 대사만으로 읽혀야 한다).
- 손님은 이름을 밝히기 전일 수 있다. **기본 편(named 없음)에서는 손님 이름 · 사연을 직접 밝히지 않는다** (말투 · 버릇 · 직업 기색으로만). 3편 중 1편까지는 `named: true` 로 이름을 밝힌 뒤에만 나오게 해 사연을 조금 더 드러내도 된다.
- 에이든은 그 손님을 단골 메뉴나 버릇으로 부른다 (명부 menu 의 메뉴 이름은 `src/data/bar/drinks.ts` RECIPES 의 name).
- 레이첼은 가끔 무대 밖에서 한마디 거들 수 있다 (짧게, 반말 기본 · 처음 보는 어른에겐 건성 해요체).

## 형식 (`src/data/bar/guestaiden.ts` 의 `GuestAidenTalk`)
```ts
import type { GuestAidenTalk } from '../guestaiden';
export const GUEST_AIDEN_A: Record<string, GuestAidenTalk[]> = {
  u_norman: [
    { sit: '카운터, 귀향 토디', lines: ['에이든: …', '…', '에이든: …', '…'] },
    { sit: '…', lines: [ … ] },
    { sit: '…', named: true, lines: [ … ] },
  ],
};
```
- 줄: `에이든: …` = 에이든, `레이첼: …` = 레이첼, **이름표 없는 줄 = 그 손님**. `* ` 서술은 쓰지 않는다.
- 한 편 4~7줄, 한 줄은 말풍선에 들어가게 1~2문장 (대략 50자 안쪽). sit 은 도감 기록용 짧은 상황 (예: '카운터, 귀향 토디').
- 3편은 서로 다른 화제 · 모양. 다른 손님 편과 같은 농담 · 같은 문장을 되풀이하지 않는다. 손님끼리 서로 아는 사이로 만들지 않는다.
- 망령 · 기계 손님은 마시는 방식 설정을 살린다. 에이든은 고대 안드로이드라 기계 손님과의 거리감도 소재가 된다 (단, 구인류 · 대승천 회고 금지).

## 확인 · 보고

- 숫자 표기: `tests/number_check.ts` 규칙 (한글 수 표기 금지).
- 보고(한국어): 손님별 3편의 sit 과 모양, 세계관에서 확신이 없던 점.
