# ERRANTEs 로어북

원본: 기획자의 옵시디언 볼트 (`[[위키링크]]`, `![[틀-…]]` 삽입 문법 사용). 파일명은 문서 제목과 같다.

| 폴더 | 내용 |
|---|---|
| `_틀/` | 옵시디언 틀(내비게이션 박스): 에란테스 조직도, 엘베스타드 가문, 연합 지역, 페트라 조직, 동맹 지역, 성도회 조직(틀-교단) |
| `세력/` | 세력·집단 문서 |
| `지역/연합` · `지역/제국` · `지역/동맹` | 섹터 · 대공령 · 도시국가 문서 |
| `인물/` | 인물 문서 (원본 시트) |
| `인물/확장/` | 대본(바 허브 · 만담 · 사건)에서 새로 생긴 인물 설정. 원본 시트는 그대로 두고 여기에 덧붙인다 |

## 확장 설정 (`인물/확장/`)

원본 시트(`인물/<이름>.md`)는 기획자 볼트의 원본이라 고치지 않는다. 게임 대본을 쓰며 새로 생긴 설정은 `인물/확장/<이름>.md` 에 적는다.

- 항목 형식: `- 설정 〔관계: 원본 확장 | 원본 해석 | 새 설정〕 〔출처: 파일 「대본 속 문구」〕`
  - 원본 확장 = 원본에 있는 사실을 구체화 · 원본 해석 = 원본의 성격 · 상처를 행동으로 옮김 · 새 설정 = 원본에 근거 없음
- 문서 머리: 원본 시트 링크(없으면 '없음'), '금지 설정:' 핵심어(docs/VOICES.md 의 금지 항목), 확인 체크리스트.
- 정합성 절차
  1. 자동 — `npm run check` 의 확장 설정 검사(tests/lore_ext_check.ts): 문서 이름이 기물 이름인지, 원본 시트 경로가 있는지, 관계 표시, 출처 파일에 「문구」가 그대로 있는지, 금지 설정 핵심어 충돌.
  2. 사람 — 문서 머리 체크리스트: 원본 인적사항(나이 · 출신 · 소속 · 가족) · 실재와 자아 해석 · 세계관 문서(세력 · 지역 · 연표)와 어긋나지 않는지.
  3. 어긋나면 원본이 아니라 대본과 확장 문서를 고친다.
