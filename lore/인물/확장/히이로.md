# 히이로 — 확장 설정

원본 시트: [[히이로]] (lore/인물/히이로.md)
대본(바 허브 · 만담 · 사건)을 쓰며 새로 생긴 설정을 모은다. 원본 시트 · 세계관 문서(lore/세력 · lore/지역)를 바꾸지 않는다. 어긋나면 이 문서 쪽을 고친다.

금지 설정: 정체 · 과거 설명

## 확인 체크리스트 (항목을 더할 때마다)
- [ ] 원본 시트 '인적사항'(나이 · 출신 · 소속 · 가족)과 숫자 · 관계가 맞는다
- [ ] 원본 '실재와 자아' · '이상과 동기' 해석과 반대 방향의 행동이 아니다
- [ ] 세계관 문서(세력 · 지역 · 연표)의 사실과 어긋나지 않는다
- [ ] docs/VOICES.md 의 '금지' 항목을 어기지 않는다 (위 '금지 설정' 줄에 핵심어를 적어 두면 자동 검사가 본다)
- [ ] 출처 대본이 실제로 있다 (자동: `npm run check` 의 확장 설정 검사가 「인용」 문구를 그 파일에서 찾는다)

## 항목
형식: `- 설정 〔관계: 원본 확장 | 원본 해석 | 새 설정〕 〔출처: 파일 「대본 속 문구」〕`

- 방문이 매일 바뀐다 (회전문 · 여닫이 · 미닫이). 〔관계: 원본 확장〕 〔출처: src/data/bar/talk_b.ts 「오늘은 회전문이에요」〕
- 고향을 물으면 기후네 · 벤데타-3 설을 둘 다 부정하지 않고, 말차라떼 얘기로 흘린다(호이슌 암시). 〔관계: 원본 해석〕 〔출처: src/data/bar/ask_a.ts 「말차라떼가 맛있는 곳이었으려나」〕
