# 예레나 — 확장 설정

원본 시트: [[예레나]] (lore/인물/예레나.md)
대본(바 허브 · 만담 · 사건)을 쓰며 새로 생긴 설정을 모은다. 원본 시트 · 세계관 문서(lore/세력 · lore/지역)를 바꾸지 않는다. 어긋나면 이 문서 쪽을 고친다.

금지 설정: 불우한 과거를 직접 말하기

## 확인 체크리스트 (항목을 더할 때마다)
- [ ] 원본 시트 '인적사항'(나이 · 출신 · 소속 · 가족)과 숫자 · 관계가 맞는다
- [ ] 원본 '실재와 자아' · '이상과 동기' 해석과 반대 방향의 행동이 아니다
- [ ] 세계관 문서(세력 · 지역 · 연표)의 사실과 어긋나지 않는다
- [ ] docs/VOICES.md 의 '금지' 항목을 어기지 않는다 (위 '금지 설정' 줄에 핵심어를 적어 두면 자동 검사가 본다)
- [ ] 출처 대본이 실제로 있다 (자동: `npm run check` 의 확장 설정 검사가 「인용」 문구를 그 파일에서 찾는다)

## 항목
형식: `- 설정 〔관계: 원본 확장 | 원본 해석 | 새 설정〕 〔출처: 파일 「대본 속 문구」〕`

- 상원 시절 "돈 받는 영웅이 제일 오래간다"는 연설문을 직접 썼고, 그 연설은 졌다. 〔관계: 새 설정〕 〔출처: src/data/bar/frames_b.ts 「제가 쓴 연설문이요」〕
- 일을 마치면 보고서 마지막 줄을 직접 쓴다 ('항로 회복 완료'). 〔관계: 원본 확장〕 〔출처: src/data/scenes/campaign.ts 「항로 회복 완료」〕
- 산노디스의 소등(펄서 펄스로 도시가 타는 축제)과 칼초를 브리핑에서 설명한다. 보안위원회가 칼초를 어디에 쓰는지는 묻지 말라고 한다. 〔관계: 원본 해석〕 〔출처: src/data/scenes/campaign.ts 「어디에 쓰는지는 묻지 마요」〕
